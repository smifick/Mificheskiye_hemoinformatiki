# Результаты и происхождение артефактов

## Основной эксперимент: final_run

- `config.json` — признаки, параметры, версии библиотек, SHA256 исходных CSV.
- `data_audit.json`, `duplicates_audit.csv` — аудит состава и повторных структур.
- `validation_splits.csv` — принадлежность outer-разделению и внутренним фолдам.
- `cv_summary.csv`, `cv_folds.csv`, `cv_predictions.csv` — сравнение 16 конфигураций и внутренние прогнозы.
- `metrics.json`, `holdout_predictions.csv` — оценка выбранной конфигурации на 52 отложенных строках.
- `model.joblib` — выбранная конфигурация, обученная на всех 320 строках.
- `training_dataset.csv` — снимок состава обучения; копия канонической таблицы `data/processed/training_dataset.csv`.
- `submission.csv` — прогноз для 597 тестовых строк; копия корневого submission.
- `prediction_diagnostics.csv` — ближайшая обучающая структура и максимальное Tanimoto-сходство.
- `test_structure_audit.csv` — стандартизованные тестовые структуры и метаданные обработки.

## Дополнительные проверки

`validation_report.json` содержит результаты независимой проверки схем и числовых инвариантов. `unit_tests.txt` — журнал пяти модульных тестов. `artifact_manifest.json` — пути и SHA256 файлов проекта; сам manifest исключён из собственного списка.

`error_analysis/` содержит группировку отложенных ошибок по типам меток, ранжирование ошибок по соединениям и сводку диагностики. Анализ выполнен после первоначальной оценки holdout. `competition_result.json` фиксирует Public MSE отдельно от локальных метрик.
