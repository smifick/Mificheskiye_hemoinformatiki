# Три модуля SMILES-only SI regression

Пакет `si_pipeline/` реализует независимый путь обучения, использующий **только структуру молекулы**. Организаторские IC50, CC50, их пропуски, Title, strain и Culture в обучение и инференс не входят. Целевая колонка используется как ответ, а не как признак.

## Установка

Python 3.12 рекомендуется для воспроизведения сохранённого прогона.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-si-pipeline.txt
# Необязательные дополнительные 2D-дескрипторы:
python -m pip install -r requirements-si-mordred.txt
```

Из корня репозитория модули запускаются через `python -m`. Пакет также можно установить командой `python -m pip install -e .` или `python -m pip install -e '.[mordred]'`.

## 1. Сбор и валидация

`si_pipeline.collect` использует requests и ChEMBL REST API: пагинацию, повторы при временных ошибках, локальный кэш ответов и SHA256-манифест запросов. Общая [документация ChEMBL API](https://chembl.gitbook.io/chembl-interface-documentation/web-services/chembl-data-web-services) описывает ресурсы assay, activity и document.

Сначала можно выгрузить кандидатов assay для **реального выбранного target ID**:

```bash
python -m si_pipeline.collect discover --target-id CHEMBL123456 --out work/assay_candidates.csv
```

`CHEMBL123456` здесь — пример формата, а не установленный ID нужной мишени. Выбирать идентификаторы необходимо по источнику; конкретная вирусная мишень в новом запросе не задана.

Для вычисления SI заполните копию `configs/assay_pairs.example.csv`. Поля:

- `context_id`: уникальный идентификатор проверенной пары экспериментов;
- `target_chembl_id`: мишень IC50;
- `ic50_assay_id`, `cc50_assay_id`: соответствующие экспериментальные assays;
- `cell_line`, `ic50_hours`, `cc50_hours`: подтверждённая клеточная линия и одинаковая длительность;
- `evidence_url`: публикация или источник, подтверждающий сопоставимость условий.

Необязательная политика `pairing_policy=author_defined_si` допускает разную или неуказанную длительность, если таблица публикации явно задаёт эту пару для SI: требуется `reported_si_verified=true` и ссылка на свидетельство. Это исключение не определяется автоматически по совпадению молекулы. По умолчанию действует `equal_duration`.

```bash
python -m si_pipeline.collect collect --pairs configs/assay_pairs.csv --out data/external_curated/si_pairs.csv
```

Пустой шаблон намеренно не содержит выдуманных assay ID. Модуль автоматически скачивает и обрабатывает записи после заполнения манифеста. Совпадение структуры и DOI само по себе не доказывает совместимость: клеточную линию, длительность и определение endpoint следует сверить с публикацией. Если метаданные API отсутствуют, основанием для объявленного контекста остаётся указанное свидетельство, а не автоматическая догадка.

Принимаются точные положительные IC50 и CC50, только с relation `=`. EC50 не подменяет IC50. `>`, `<`, неизвестные операторы, немолярные единицы, ошибки валидации ChEMBL, помеченные потенциальные дубликаты и некорректные SMILES отклоняются. Значения M/mM/µM/nM/pM/fM приводятся к µM; регистр `M` и `mM` сохраняется. Репликаты одного разрешённого assay агрегируются геометрическим средним; независимые контексты не усредняются.

Структуры нормализуются RDKit: крупнейший органический компонент, нейтрализация, канонизация таутомеров и канонический изомерический SMILES. Правила одинаковы при сборе и обучении. Стереоизомеры сохраняются как разные представления, но остаются вместе при scaffold CV.

Выход строго соответствует схеме:

```text
smiles,IC50_uM,CC50_uM,SI,doi
```

Дополнительно сохраняются `.provenance.csv`, `.rejected.csv` и `.requests.json`: контекст, assay/activity ID, публикация, причины исключения и хеши API-ответов. При отсутствии корректного DOI поле пустое. PubChem BioAssay можно использовать как дополнительный источник кандидатов и первичных описаний; в этой версии сетевой коннектор реализован для ChEMBL. Данные разных баз не объединяются автоматически без сверки assay-семантики.

## 2. Признаки, модели и scaffold CV

`MolecularFeatures` вычисляет 217 RDKit-дескрипторов в текущей версии, 167 MACCS keys и 2048 счётчиков Morgan с log1p-преобразованием. Всего в базовом варианте — **2432 признака**. Флаг `--mordred` добавляет 2D-дескрипторы [mordredcommunity](https://pypi.org/project/mordredcommunity/); 3D-конформеры не требуются. Порядок колонок сохраняется в модели, а несовместимая версия RDKit/схема дескрипторов вызывают ошибку вместо тихой смены признаков.

Сравниваются четыре заранее заданных семейства: регуляризованная Ridge/LogisticRegression, Extra Trees, LightGBM и CatBoost. Для деревьев ограничены глубина/число листьев и минимальный размер листа, заданы L1/L2-регуляризация, доля признаков и фиксированные seeds. Важность этих параметров для малых выборок обсуждается в [документации LightGBM](https://lightgbm.readthedocs.io/en/latest/Parameters-Tuning.html). Масштабирование и импутация обучаются внутри фолда, а не на всей выборке.

Реализована вложенная CV: 5 внешних scaffold-фолдов и 3 внутренних для выбора семейства и веса внешних данных. Generic Bemis–Murcko groups вычисляются после той же нормализации структур. Внешние обучающие записи с совпадающим валидационным каркасом или родительской структурой исключаются на обоих уровнях. Сохраняются состав фолдов, OOF-прогнозы, результаты внутреннего поиска и оценка константного baseline. Scaffold CV проверяет перенос на новые каркасы; состав скрытого Kaggle test может отличаться, поэтому равенство локальной и leaderboard-оценки не предполагается.

Для текущей соревновательной разметки:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m si_pipeline.train --train data/raw/train.csv --smiles-col SMILES --target-col 'SI VACV' --mode encoded --sentinel 10000 --out results/modular_reproduced
```

В режиме `encoded` целевой код 10000, по разъяснению организаторов, отражает отсутствие IC50, связанное с неактивностью в их данных. Он **не является измеренным SI**. Классификатор оценивает вероятность кода по SMILES; регрессор — условный числовой SI на положительных метках, отличных от кода. Доля нулевых технических меток оценивается только на обучающей части. Финальный числовой ответ согласован с кодированной целью. Код 10000 не используется как верхняя граница физического SI.

Проверенные внешние строки в этом режиме добавляются **только в числовую ветвь**. Для классификатора не придумываются внешние метки активности. Безусловное объединение физических внешних SI с техническими кодами соревнования было бы некорректно.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m si_pipeline.train --train data/raw/train.csv --external data/external_curated/si_pairs.csv --external-weight 0.25 --mode encoded --out results/modular_with_external --mordred
```

При наличии внешних строк выбор модели включает варианты с весами 0 и 0.25: добавление данных должно подтвердить полезность по CV. Взаимная совместимость измерений IC50/CC50 ещё не гарантирует, что их контекст совпадает с распределением соревнования.

Если готовая внешняя таблица использует имя `SMILES` в верхнем регистре, добавьте `--external-smiles-col SMILES`. Смысл внешних SI и происхождение строк следует проверить до запуска; поля концентраций из внешнего CSV также не загружаются как признаки.

Для отдельного набора настоящих положительных SI без технической кодировки:

```bash
python -m si_pipeline.train --train measured_si.csv --smiles-col smiles --target-col SI --mode ratio --out results/physical_si
```

В `ratio`-режиме SI=10000 может быть обычной числовой меткой: classifier и фильтрация sentinel не используются. Для сильного перекоса цели можно отдельным экспериментом проверить log1p-регрессию с внутренней калибровкой обратного преобразования. Здесь основной отбор выполняется по MSE в исходных единицах, без необоснованной log-оптимизации.

Предобученные ChemBERTa/MoLFormer embeddings — следующая гипотеза, а не заявленный результат: на малом датасете стоит заморозить encoder и обучать регуляризованную голову на тех же фолдах. Эта версия реализует альтернативу с Mordred и не скачивает непроверенные веса нейросетей. Randomized SMILES не создают новые независимые молекулы; все варианты записи необходимо удерживать в одной группе.

## 3. Инференс и Kaggle submission

```bash
python -m si_pipeline.predict --model results/smiles_only_modular/model.joblib --test data/raw/test.csv --sample data/raw/sample_submit.csv --out work/submission_modular.csv
```

Вход может содержать только `SMILES`. Необязательный `index` переносится в результат; без индекса используется порядок sample либо 0..N−1. Из sample читаются **только индексы**, не его демонстрационные числовые значения. Проверяются уникальность и согласованность индексов, конечность и неотрицательность прогнозов. Выход имеет колонки `index,SI VACV` для текущего проекта; имя цели сохраняется из команды обучения.

Вместе с моделью сохранены featurizer, правила преобразования, схема признаков, версии и выбранные estimators. Повторный инференс не читает обучающие данные, концентрации или внешние API.

## Проверенный прогон и ограничения

На исходных 320 строках выполнен полный nested scaffold benchmark без новых внешних данных. После канонизации таутомеров сформировано 118 групп; схема отличается от старых v6/v7, поэтому прямое сравнение чисел между ними некорректно. Выбрана Extra Trees: выбранная OOF MSE 18010402.85; вложенная MSE процедуры поиска 19050686.05; baseline на тех же фолдах 22547795.87. Public score нового CSV неизвестен. Код является проверенным базовым пайплайном, а не доказанным улучшением лучшей отправки.

Новый внешний обучающий банк в этом запуске не объявляется собранным: для абстрактной мишени не заданы конкретные проверенные пары assay. Ранее сохранённые внешние таблицы проекта не подмешивались автоматически. Сетевой сбор и валидация пар покрыты независимыми тестами с контролируемыми API-ответами.

После этого пользователь предоставил `vacv_si_all_cells.csv` и `vacv_si_vero.csv`. Проверка показала: 56 и 38 измерений, по 38 уникальных структур в каждом; Vero полностью входит в all_cells. Все 56 пар совпадают с уже имеющимися `data/external_curated/vacv_si.csv` по структуре, DOI, клеточной линии и концентрациям. Арифметика SI=CC50/IC50 согласуется с точностью 1e-8. Это существующий банк, а не 94 независимые новые метки.

Из 38 структур три присутствуют в organizer train, 16 — в test, 19 отсутствуют в обоих. В all_cells добавлены измерения A549 для тех же 18 структур; медианное межклеточное различие SI — 2.53 раза, максимальное — около 9 раз. При скрытом контексте это вариабельность метки одной структуры, а не новые молекулы. Высокое значение SI=127600 сохраняется как измеренная метка; его нельзя приравнивать к коду неактивности или механически обрезать до 10000.

Проверена абляция Extra Trees на **одинаковых** scaffold-фолдах, с исключением валидационных структур/каркасов из внешнего обучения и добавлением внешних строк только в числовую ветвь:

| Обучение | OOF MSE |
|---|---:|
| Только organizer train | 18010402.85 |
| + Vero, внешний вес 0.25 | 18281333.76 |
| + все клетки, внешний вес 0.25 | 18376927.95 |

По итоговому отбору выбран вес 0. При этой конфигурации улучшение от добавления банка не получено; вывод не исключает полезность других представлений, весов или предобучения. Сводки сохранены в `external_data_audit.json` и `external_ablation.csv`. Загрузки пользователя не публикуются повторно: числовые измерения уже имеются в исходной открытой таблице проекта.

В приложенных train/test подтверждены 320/597 строк и побайтовое совпадение с репозиторием. В train — 312 родительских структур; 6 из 8 повторных структур имеют разные метки, но эти конфликты исчезают при учёте исходных strain/Culture. Это показывает информационное ограничение SMILES-only задачи; по последнему условию эти поля всё равно исключены. Строки strain с упоминанием других вирусов не интерпретировались как доказательство принадлежности целевого измерения к этим вирусам.

```bash
python -m unittest discover -s tests -p 'test_si_pipeline.py' -v
python -m unittest discover -s tests -v
```

Тестируются единицы, цензурирование, совместимость источников, репликаты, канонические эквиваленты SMILES, Mordred, изоляция валидационных меток, исключение внешних валидационных структур, раздельность scaffold-фолдов и неизменность инференса после подмены запрещённых колонок.

Пройдены 30 автоматических тестов. Выполнены сборка Python wheel и реальный запрос статуса ChEMBL API. Сохранённая модель воспроизводит 597 прогнозов с максимальным отклонением около 2e-12; подмена всех запрещённых входных колонок не меняет результат.
