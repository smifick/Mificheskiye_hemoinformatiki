Два эксперта определены точно:

- **S — развёрнутая v7**, `results/v7_final/model.joblib` / `submission_candidate_v7.csv`, а не альтернативная полная feature-версия из `results/v7/`. Классификатор технического кода использует legacy Morgan2048+torsion KRR и feature-Morgan8192 KRR. Он усредняет 50:50 два уже готовых SI после исходной F/clipping. Оба классификатора обучаются на source-absent organizer-строках. Физическая ветвь — прежний log1p KRR с Duan smearing и V/C банком.
- **M — PR #3**, `results/audit_20261107/selected_model.joblib`: 50:50 вероятности notation logistic C=1 (девять статистик записи) и raw ChemBERTa-MLM logistic C=0.1 (768 frozen mean+CLS признаков), затем исходная F/clipping. Голова нотации не называется структурной. Обе головы обучены только на source-absent строках; source-present получает прежнюю общую вероятность.

Уровень новой композиции — **готовый SI после clipping каждого эксперта, перед общим lookup**:

```text
numeric = wS*S_SI + (1-wS)*M_SI
final = original_clipped_lookup if covered else numeric
```

При wS=0 получается production PR #3. Постоянная смесь этой же пары 50:50 уже проверялась в PR #3 как `notation_mlm_probability_average_blend50`; здесь дополнительно оценивается оптимальный по обучающим OOF постоянный вес. Так выигрыш от изменения экспертов отделён от выигрыша динамического веса.

Близость s — максимум Tanimoto по **фактическим** Morgan radius2/2048/chirality из `V7.T.std` и `V7.T.mg`, согласованным с legacy CODE-ветвью A структурного эксперта. Reference bank — только source-absent organizer-строки, на которых обучена эта ветвь. Внешние и тестовые структуры в него не входят. Production bank содержит **231 строку** и точно совпадает с сохранённым `A_reference.bits`. Физическая B-ветвь имеет другой обучающий банк; показатель s определён относительно A, а не относительно B.

Расхождение d = abs(S_SI−M_SI)/10000. Оно не содержит меток или ошибок экспертов. Gate:

```text
wS = clip(w0 + beta_s*(s-s0) + beta_d*(d-d0), 0, 1)
```

w0 — аналитически оптимальная постоянная смесь на соответствующих training OOF; s0,d0 — средние этой же calibration-части. Центры сохраняются в JSON и при inference не пересчитываются. βs∈[0,0.5], βd∈[−0.5,0.5]. Сравниваются constant, s-only, d-only и s+d; для динамических вариантов λ∈{0.01,0.1,1}. Минимизируется `mean(((final-y)/10000)^2) + λ*mean((w−w0)^2)`. Это только численное масштабирование обычной MSE и регуляризация отклонения веса; целевые метки не преобразуются. Для w0=0/1 предусмотрены ненулевые допустимые старты, а не блокирующая границы sigmoid-параметризация. Свободный знак βs в эту проверку не добавлялся.

Выполнена вложенная проверка с дополнительным уровнем для честного выбора регуляризации:

1. Пять внешних scaffold-фолдов читаются из исходного `results/v2/validation_splits.csv`.
2. Outer-train разделяется на три tuning-фолда, seed314.
3. Для каждого tuning-train создаются ещё три subinner OOF, seed271. Эксперты, формирующие calibration-прогнозы gate, не видят ни tuning-validation, ни outer-validation.
4. Gate обучается на этих calibration-OOF и оценивается на tuning-validation, предсказанном экспертами tuning-train. Так выбираются family/λ; это не meta-CV глобального OOF-массива.
5. Выбранный gate refit на OOF всего outer-train; внешние эксперты обучаются на outer-train, а s считается по их собственному reference bank. Затем оценивается outer-validation.

Внешний численный банк исключает структуры и каркасы всех соответствующих held-out уровней. Source-приоры и zero_rate считаются только по обучающим меткам. Lookup в OOF выключен, как в оригинальном PR #3; production lookup сохранён последней операцией. Параметры каждого gate, индексы/хеши обучающих моделей и reference banks опубликованы. Проверено **207** различных экспертных конфигураций reference bank; provenance сохраняет разрешённые строки и блокированные группы.

«Оптимальный постоянный» здесь означает выбранный **на обучении каждого внешнего фолда**. Он может проигрывать неизменному production-весу на проверке. Описательный подбор одного постоянного веса по глобальным внешним OOF дал wS=0; это диагностический, оптимистичный расчёт, не новая независимая оценка и не вход в gate.

| Схема | PR #3 | Обучаемый constant | Выбранный gate | Gate против PR #3 |
|---|---:|---:|---:|---:|
| Архивные фолды | **11 341 011** | 11 413 327 | 11 349 151 | +0,0718% |
| Повтор seed6611 | **10 241 914** | 10 371 926 | 10 328 268 | +0,8431% |
| Повтор seed6612 | **9 928 340** | **9 928 340** | 9 929 448 | +0,0112% |

Относительная полезность оценена через `delta_SE=(S-y)^2−(M-y)^2` на внутренних OOF. Среди строк с различающимися экспертами **во всех пяти диапазонах s** средняя и медианная delta_SE положительны: M в среднем лучше S. Например, для s≤0.3 средняя delta_SE≈7.80 млн, для 0.5<s≤0.7≈11.23 млн. Высокий диапазон s>0.9 содержит всего **две уникальные строки и два каркаса**; сильный вывод для почти идентичных структур по нему делать нельзя. При увеличении d преимущество M в среднем возрастает. Рост/падение собственной ошибки S не подменялось доказательством относительного преимущества.

Добавление s сверх d уменьшило MSE на **0,483%** в основной схеме и **0,044%** в seed6611, но ухудшило на **0,182%** в seed6612. s-only на основной проверке совпал с constant. **Устойчивой добавочной пользы s не подтверждено.** Все интервалы s/d были зафиксированы заранее; диагностические таблицы не использовались для изменения конструкции после внешней оценки. Повторные появления строк в training-диагностике отмечены отдельно от числа уникальных структур/каркасов.

Gate улучшил основной обучаемый constant суммарно на 20,54 млн SSE; крупнейшая положительная строка даёт **10,53%** выигрыша. Эффект против этого контроля не объясняется одним наблюдением. Но относительно production суммарная ошибка выросла. В частности, MSE малых SI≤100 увеличилась с **3 856 495** до примерно **3 871 253**. Source-present группа неизменна, включая экстремальный SI≈36 067 с прежним прогнозом≈331; смешивание этих экспертов не может исправить этот экстремум.

Парный bootstrap 117 scaffold-групп (2000 повторов, seed8137) дал 95% интервал уменьшения MSE **только относительно обучаемого constant**: [8480,57; 145736,86]. Он не является интервалом улучшения относительно PR #3. Все данные уже участвовали в разработке; повторы не являются новыми независимыми наблюдениями, а bootstrap не учитывает полностью историю выбора исследовательских гипотез.

Сходство имеет заметный сдвиг между этапами. Для source-absent средний s растёт примерно **0.369 → 0.399 → 0.412 → 0.662**: subinner calibration → inner validation → outer validation → production. Средний размер reference bank — примерно **81 → 122 → 178 → 231**. Размер банка и отличие test от scaffold-held-out областей ограничивают переносимость gate. Нормировка по текущему inference-batch для «исправления» этого сдвига не вводилась.

Реальное влияние пересчитано заново, без переноса числа 157 из PR #8. S/M различаются на **401 test-строке, 384 структурах, 142 каркасах**, исключительно в source-absent группе. Все 196 source-present прогнозов совпадают, в том числе 39 lookup-строк; lookup не скрывает дополнительных различий пары. Во внешней основной проверке выбранная процедура изменила 78 строк, 77 структур и 38 каркасов. Финальная training-процедура выбрала имя `sd_lambda0.01`, но после refit получила **w0=βs=βd=0**. Её фактический эффект на test — **ноль**.

Проверки прошли: **21 unit test** для нулевых коэффициентов, границ w0=0/1, конечности и диапазона весов, неизменности batch-центров, перестановок, lookup, JSON round-trip, alpha_source=0. Production replay: M до **6.37e−12**, S до **1.82e−12**. Все 207 reference banks совпадают с фактическими training source-absent строками и не содержат held-out групп/дубликатов. Внешние y в фолде с ненулевым gate заменены на NaN и 1e12; все экспертные и calibration-модели пересчитаны в пустых кэшах. Выбранные family/λ/параметры не изменились, отклонение прогнозов≤**2.28e−13**. Настоящий CLI проверен на 597 чистых/испорченных/переставленных строках и отдельно с ненулевым диагностическим gate; максимальное расхождение≤**1.82e−12**.
