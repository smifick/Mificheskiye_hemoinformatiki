# Парсер ChEMBL для задачи SMILES → SI VACV

VACV — вирус вакцинии (Vaccinia virus), а не штамм вируса натуральной
оспы Variola virus. Парсер собирает опубликованные измерения
противовирусной активности и цитотоксичности для проверки меток SI.

## Запуск из корня репозитория

Нужны Python 3.11+ и зависимости проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/download_external.py --out data/chembl_refresh --cache work/chembl_cache
```

Используется публичный REST API https://www.ebi.ac.uk/chembl/api/data/;
ключ доступа не требуется. Для повторной загрузки вместо кеша добавьте
`--refresh`. Дополнительные параметры: `--workers 4`, `--page-size 1000`,
`--timeout 60`. В Windows активация окружения: `.venv\Scripts\activate`.

## Отбор и выходные данные

Поиск объединяет организм анализа, описание с `vaccinia`, описание с `VACV`
и привязку к найденным organism-level мишеням Vaccinia. Так обнаруживаются
также анализы, в которых организмом указана клетка хозяина. Среди результатов
бывают посторонние записи: VACVase человека, эксперименты с использованием
вакцинии как системы экспрессии.

Подтверждённая группа — функциональные анализы (`assay_type=F`) с мишенью
типа `ORGANISM`, относящейся к Vaccinia. Для функциональных анализов
с неоднозначной мишенью измерения загружаются отдельно для проверки.
Молекулярные мишени и нефункциональные анализы отмечаются в журнале поиска.
Область охвата задана явно; выгрузка не гарантирует обнаружение каждого
эксперимента в литературе.

Загружаются `IC50`, `EC50`, `CC50`, `SI`, `Selectivity index`:
SMILES, значения, операторы сравнения, единицы, DOI, ChEMBL ID,
описания анализов, клеточные линии и доступные сведения о штамме.
Дополнительно загружаются CC50 из тех же публикаций, включая анализы
незаражённых клеток. Пригодность CC50 для конкретной пары требует проверки.

| Выходной файл | Содержание |
|---|---|
| `external_endpoints.csv` | Все измерения, исходные и нормализованные значения, релевантность и причины отбраковки |
| `review_required_endpoints.csv` | Измерения с неоднозначной привязкой к VACV |
| `assay_search_audit.csv` | Найденные анализы, маршруты поиска и решение об отборе |
| `collected_database.csv` | Компактная таблица SMILES, концентраций, SI, DOI и статусов |
| `candidate_si_pairs.csv` | Предварительные отношения CC50/IC50 и CC50/EC50 |
| `external_si_database.csv` | Предварительные отношения только CC50/IC50 |
| `direct_si.csv` | Положительные точные SI из подтверждённых анализов; определение требует проверки |
| `raw_activities.json` | Исходные записи активности API |
| `vacv_assays.json`, `all_assays.json`, `targets.json`, `documents.json` | Метаданные анализов, мишеней и публикаций |
| `chembl_status.json` | Версия ChEMBL до и после загрузки |
| `request_manifest.json` | URL, SHA256 ответов, время и сведения об использовании кеша |
| `collection_summary.json` | Статистика успешной загрузки |

`is_vacv_assay=True` — подтверждённая привязка к VACV;
`validation_status=valid_endpoint` — прохождение технических проверок.
Поле `vacv_selection_status` объясняет происхождение записи.
Даже сочетание этих условий не подтверждает сопоставимость двух анализов.

Проверяются полнота пагинации, уникальность ID и неизменность версии базы.
Временные сетевые ошибки повторяются. При ошибке загрузки процесс завершается
с ненулевым кодом и сохраняет журнал выполненных запросов.
`collection_summary.json` появляется при успешном завершении выгрузки;
при обновлении каталога старый итоговый файл удаляется заранее.
Кеш разделён по версиям ChEMBL.

## Получение меток SI

Концентрации переводятся в микромоли/литр. Операторы `>`, `<`, `>=`, `<=`
сохраняются как границы и исключаются из расчёта точных отношений.
Нули, отрицательные и бесконечные значения, неизвестные единицы,
невалидные SMILES и записи с флагами качества ChEMBL также исключаются.
Исходные поля сохраняются для проверки.

Предварительная пара требует одинаковых `molecule_chembl_id` и
`document_chembl_id`. Совпадение клеточной линии и извлечённого времени
инкубации отмечается отдельным статусом; первоисточник всё равно проверяется.
Извлечение времени из текста — простая эвристика. Авторы могут обоснованно
использовать разную длительность двух анализов.

Встречаются определения `SI = CC50 / IC50` и `SI = CC50 / EC50`.
Знаменатель записан в `denominator_endpoint`, формула — в `si_definition`.
Определение нужно согласовать с целевой переменной перед объединением данных.

Примеры публикационной проверки находятся в `src/curate_external.py`
и `data/external_curated/`. Новая выгрузка сохраняется в `data/chembl_refresh`;
зафиксированный набор прошлых экспериментов — в `data/external`.
Автоматически допущенных новых обучающих меток у парсера — **0**.

## Обучение по SMILES и расчёт MSE

`src/train_model.py` строит Morgan/RDKit-признаки по SMILES, выбирает модель
по внутренней scaffold CV, оценивает на отложенных каркасах и обучает
итоговую модель. Запуск на уже имеющемся наборе:

```bash
python src/train_model.py \
  --train data/raw/train.csv \
  --test data/raw/test.csv \
  --sample data/raw/sample_submit.csv \
  --out results/new_model_run
```

Каталог `--out` должен быть новым. Результаты: `metrics.json`,
`holdout_predictions.csv`, `model.joblib`. Внешние пары требуют проверки
перед добавлением в обучающий набор.

```python
import pandas as pd
from sklearn.metrics import mean_squared_error

d = pd.read_csv("results/new_model_run/holdout_predictions.csv")
print(mean_squared_error(d["observed"], d["prediction"]))
```

`MSE = mean((SI_observed - SI_predicted)**2)` считается в исходной шкале SI.
Ошибка по `log(SI)` — другая метрика. Молекулы одного каркаса следует
держать в одной части выборки; подбор модели выполняется внутри обучения.
Для MSE необходимы истинные метки и предсказания отложенных наблюдений.

В `data/raw/train.csv` имеются технические коды пропусков, включая 10000
при отсутствующем IC50. Обучение на этой колонке оценивает соревновательную
цель. Для регрессии физического SI нужны проверенные отношения концентраций.

## Проверка парсера

```bash
python -m unittest discover -s tests -p test_download_external.py -v
```

Проверяются единицы, границы, нулевые SI, разделение IC50/EC50,
запрет пар между разными публикациями/молекулами, отбор анализов,
кеш и полнота пагинации.

Контрольная загрузка ChEMBL 37: 864 найденных анализа, 584 подтверждённых
функциональных анализа; 2182 VACV-измерения, 218 неоднозначных измерений
и 4453 дополнительных CC50. Всего 6853 уникальные записи,
из них 2735 технически допустимы. Получено 329 предварительных пар:
152 CC50/IC50 и 177 CC50/EC50. Подробности:
`results/chembl_parser_check/collection_summary.json`.

Контрольное воспроизведение существующего обучения на 320 организаторских
строках дало прежнюю выбранную модель Tanimoto KRR (alpha=1):
MSE 12 350 204.88 на 52 отложенных строках, против 18 385 782.55
у среднего по обучающей части. Это повтор существующего эксперимента
с техническими кодами в целевой колонке; новая независимая оценка
биологического SI здесь не выполнялась. Метрики сохранены в
`results/chembl_parser_check/model_reproduction_metrics.json`.

Источник: ChEMBL / EMBL-EBI. Условия использования:
https://chembl.gitbook.io/chembl-interface-documentation/about/terms-of-use .
DOI и ссылки на исходные записи сохраняются для атрибуции.
