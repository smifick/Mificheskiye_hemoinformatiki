# Отдельный эксперимент: обучение только на 237 измеренных SI

Подтверждено по исходному `data/raw/train.csv`: **81 строка без IC50 имеет SI=10000**, **две строки без CC50 имеют SI=0**. Пересечения групп нет. Других SI=10000 или SI=0 в train нет. На остальных **237 строках** обе концентрации заполнены и положительны, а SI совпадает с CC50/IC50 с округлением до трёх знаков; максимальное расхождение составляет 0,0005. Соответствие кодов пропускам доказано данными, хотя само по себе не устанавливает намерения авторов кодировки.

Эти 83 строки исключены **только из нового эксперимента**. Исходный train, прежние модели и submission не менялись. Фильтр основан на пропусках концентраций, а не на числовом значении SI: если бы реально измеренный SI был равен 10000, он остался бы в обучении. SI не пересчитывался из концентраций и не корректировался. Экстремум 36 066,667 сохранён.

Один фиксированный алгоритм — **raw Tanimoto Kernel Ridge, α=1**, Morgan radius=2, 2048 бит, chirality, канонизация таутомеров как у исторической v3. Параметры зафиксированы до обучения; поиска архитектуры или параметров не было. Ни ансамбля, ни classifier технического кода, ни source-membership, ни внешних данных, ни log-target, ни sample weighting нет. Большие прогнозы не обрезаются сверху.

На исходных пяти scaffold-фолдах выполнены два независимых CV-контроля одного алгоритма:

- `control_all320`: обучение на всех строках обучающей части фолда;
- `filtered237_only`: обучение только на строках этой обучающей части с обеими концентрациями.

Оба варианта предсказывают **одни и те же валидационные молекулы**. Их прогнозы не смешиваются. Финальная сохранённая модель — один новый fit только на 237 строках; контрольные модели из CV в неё не входят. Концентрации нужны только для отбора обучающих строк и аудита. В признаки и при inference поступает только SMILES; из test читаются только SMILES и index.

| Одинаковые оцениваемые строки | Число | MSE обучения со всеми строками | MSE обучения без кодовых строк | Изменение MSE |
|---|---:|---:|---:|---:|
| Только измеренные SI | 237 | 10 649 287 | **6 068 782** | **−43,01%** |
| Измеренные SI ≤100 | 198 | 5 853 790 | **284 679** | **−95,14%** |
| Измеренные SI >100 | 39 | **34 995 656** | 35 434 230 | +1,25% |
| Все исходные метки, включая коды | 320 | **18 888 579** | 28 994 513 | +53,50% |

Удаление кодовых строк заметно улучшило прогноз малых измеренных SI: MAE по всем 237 измеренным значениям уменьшилась с **1983,77 до 467,17**. Однако хвост не исправлен: для SI=**36 066,667** новый OOF-прогноз — **29,33**, против **1585,24** у контроля. Улучшение средней ошибки физических SI достигнуто за счёт малых значений, а не лучшей экстраполяции экстремума.

Если Kaggle использует аналогичную кодированную цель, очищенная регрессия перестаёт воспроизводить значения 10000 для строк с неопределённым физическим SI. Поэтому её полная MSE ухудшается. **6,07 млн на 237 строках нельзя сравнивать с 11,34 млн PR #3 на 320 строках и объявлять улучшением submission.** Этот эксперимент проверяет влияние удаления кодов при неизменном алгоритме; это не подбор лучшей возможной модели на очищенном наборе. Новый Kaggle score неизвестен, submission не отправлялся.

Сохранены отдельные результаты в `results/observed_si_only_20261107/`:

- `training_data_filtered237.csv` — точные 237 строки финального обучения;
- `excluded_rows83.csv` — исключённые строки и причина исключения;
- `cohort_and_splits.csv`, `oof_predictions.csv` — исходные номера строк, остовы, фолды и два отдельных прогноза;
- `comparison.csv`, `fold_metrics.csv`, `effect_summary.json` — метрики с явным указанием оцениваемой подвыборки;
- `model_filtered237.joblib` — единственная финальная модель этого эксперимента;
- `submission_filtered237.csv` — отдельный CSV на 597 тестовых молекул;
- `protocol.json`, `data_audit.json`, `manifest.json`, `validation.json` — протокол, аудит, версии, SHA256 и проверки.

Контроль точно воспроизводит историческую v3: максимальная разница OOF-прогнозов **1,05×10⁻¹¹**. Подтверждены отсутствие всех 83 исключённых строк в финальной модели, сохранение экстремума, независимость обучения от отравления validation-меток и исключённых меток, отсутствие верхнего clipping. Реальный CLI на SMILES-only CSV и на переставленном CSV с испорченными IC50/CC50/таргетом/метаданными воспроизводит submission **без численных расхождений**. Все оценки — обычная невзвешенная MSE. Все 320 молекул уже использовались в исследованиях проекта; нового независимого holdout нет.

Воспроизведение из корня репозитория:

```bash
python -m venv work/observed_si_venv
work/observed_si_venv/bin/pip install -r requirements-observed-si-only.txt
export OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2
work/observed_si_venv/bin/python src/observed_si_only.py train --out work/observed_si_reproduction
work/observed_si_venv/bin/python src/validate_observed_si_only.py --out work/observed_si_reproduction
work/observed_si_venv/bin/python src/observed_si_only.py predict \
  --model work/observed_si_reproduction/model_filtered237.joblib \
  --input data/raw/test.csv --out work/observed_si_reproduction/replayed_submission.csv
```

Обучение отказывается перезаписывать существующий каталог результатов. Для нового повторения следует задать новый `--out`. Все файлы этой работы находятся в отдельной ветке `experiment/observed-si-only`, основанной непосредственно на PR #3, без включения исследования PR #5.
