# Двухкомпонентная регрессия: источник-отложенная проверка v4

## Статус и результат

Реализованы отдельная оценка технического кода, физическая регрессия SI, мягкое объединение, кросс-фолдовая калибровка и абляция внешних весов. **Выигрыш не получен:** выбранная двухкомпонентная конфигурация имеет scaffold OOF MSE **20038362.56**, исходная таутомерная KRR на тех же фолдах — **18888578.92**. Ошибка выше на **6.09%**. Экспериментальный CSV сохранён в результатах и не рекомендуется как улучшение Kaggle.

Лучший известный Public MSE проекта остаётся у v2: 9681096.22474. Зафиксированный результат v3: 9929683.57063. Локальные CV-оценки и Public MSE имеют разные проверочные выборки.

## Источники и пригодность

Используется ранее выполненная ChEMBL-выгрузка с activity ID, SMILES, endpoint, единицами, оператором отношения, клеточной линией и DOI. Общая таблица содержит 6510 endpoint-записей, но её строки не являются 6510 независимыми SI. Каждая запись классифицирована в external_suitability.csv: подтверждённый участник публикационной пары; цензурированный endpoint; прямой SI для проверки; отдельное точное измерение без подтверждённой пары; отклонённая запись/ручная проверка. Итоги — suitability_summary.json.

Проверенные SI основаны на двух публикациях: [Wang et al., 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10290961/) и [Suslov et al., 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7651861/). Для SI сохраняются одна молекула, клеточная линия и авторское определение пары. Банк содержит 56 проверенных строк; для текущей проверки выбран Vero-контекст. Структурная атрибуция использует ChEMBL и численную сверку таблиц, без независимого распознавания изображений структур.

## Разделение по публикациям

Источник внешнего обучения зафиксирован как DOI 10.1016/j.ejmech.2023.115601; источник внешней проверки — DOI 10.1039/d0md00108b. Это разделение записано в protocol.json до обучения и вычисления проверочных метрик.

Из внешней проверки удалены совпадения с организаторскими train и test после стандартизации и канонизации таутомеров. Осталось **19 строк и 19 структур** отдельной публикации. Из внешнего обучения исключены пересечения с test и проверочным источником. Остались **две Vero-записи двух молекул**. Эти молекулы уже встречаются в организаторском train; добавляются другие контекстные измерения, а не новые структуры. На каждом внутреннем/внешнем фолде исключаются внешние записи с валидационными каркасами.

Публикации изучались и использовались в прежних экспериментах. Поэтому данная проверка является **ретроспективной проверкой по источнику для нового зафиксированного протокола**, а не глобально нетронутым перспективным тестом. Одна отложенная публикация не даёт устойчивой оценки по множеству лабораторий.

## Компонент A: техническая метка

Организаторский train загружается только с SMILES и SI VACV. Бинарная вспомогательная цель — равенство разрешённой целевой метки 10000; это не метка биологической неактивности. Внешние SI не участвуют в обучении классификатора.

Классификатор — LogisticRegression, C=1. На обучающей части каждого внешнего фолда строятся групповые OOF logits по трём внутренним фолдам. На них оценивается sigmoid-калибратор; после этого базовый классификатор переобучается на всей обучающей части. Валидационные метки не входят в калибровку.

OOF Brier: **0.167586**, константная вероятность из обучающей части фолда: **0.191378**. OOF ROC AUC: **0.7386**. Прогноз технической метки лучше константного по Brier, но этого недостаточно для выигрыша итоговой регрессии.

## Компонент B: физический SI

Физическая регрессия использует положительные организаторские метки, отличные от 10000, и проверенные внешние SI. Нулевые метки исключаются из физического обучения, но сохраняются в общей соревновательной оценке; они не интерпретируются как измеренный SI=0.

Регрессор — KRR с Tanimoto-ядром по Morgan fingerprints, alpha=1. Проверяются исходная шкала SI и log1p(SI). Для log-модели на трёх внутренних групповых фолдах получаются прогнозы физической обучающей части. По ним, в исходной шкале, оценивается неотрицательная аффинная поправка a*r+b методом NNLS. Она никогда не обучается на внешнем валидационном фолде. Коэффициенты сохранены в log_correction.csv. Дополнительно проверена одна log-модель без поправки.

Веса внешних наблюдений: 0, 0.1, 0.3 и 1.0. Классификатор A и внешние фолды одинаковы для всех вариантов; меняется только компонент B.

## Итоговый прогноз

prediction = 10000*p_code + (1-p_code)*physical_SI.

Используется мягкая вероятность. Оба компонента вычисляются только по SMILES. Входные организаторские IC50, CC50, их пропуски, названия, культура и штамм не загружаются для обучения или прогнозирования. Для источников DOI/клеточная линия используются как фильтры качества данных, не как признаки.

## Внешняя проверка физического SI

На этой выборке проверяется только B: публикационные физические SI нельзя сравнивать с кодом 10000. Внешняя MSE поэтому не является оценкой соревнования.

| Физическая модель | MSE | MAE |
|---|---:|---:|
| mixture_raw_external_0.0 | 835895746.84 | 6862.23 |
| mixture_log_calibrated_external_0.0 | 789868759.85 | 6900.78 |
| mixture_log_calibrated_external_1.0 | 789910320.32 | 6901.15 |

Максимальный проверочный SI — 127600. Контрольное соединение ST-246 даёт **99.966%** суммы квадратов ошибок выбранного физического компонента. Оно сохранено в основной оценке, а не удалено ради улучшения показателя. Это показывает чувствительность MSE к масштабу и составу маленькой внешней выборки.

## Выводы

Проверенная внешняя выборка оказалась существенно меньше сырой выгрузки. Две дополнительные контекстные записи не образуют полноценного расширения химического пространства. Калибровка вероятности технического кода улучшила Brier относительно константы, но комбинация с физической регрессией не превзошла исходную модель по MSE. Данные об одном химическом соединении в разных экспериментах не задают единственный контекст-независимый SI.

Новая гипотеза проверена без обещания роста рейтинга. Для следующего независимого эксперимента нужен дополнительный источник с новыми структурами и проверенными сопоставимыми измерениями. Расширение числа строк через дубликаты или несовместимые пары не решает эту задачу.

## Воспроизведение

```bash
python src/two_component_v4.py --root . --out results/v4_reproduced
python src/diagnose_two_component_v4.py --root .
python src/predict_two_component_v4.py --parameters results/two_component_v4/model_parameters.json --input data/raw/test.csv --out results/repeated_v4.csv
python -m unittest discover -s tests -v
```

Каталог обучения должен быть новым. Диагностический скрипт читает зафиксированный results/two_component_v4. Параметры модели представлены прозрачным JSON, без исполняемой бинарной сериализации. Прогноз из JSON совпадает с сохранённым submission с допуском 1e-12. Модульные тесты проверяют мягкую формулу, независимость классификационной калибровки от валидационных ответов и независимость log-поправки от валидационных ответов.

Артефакты: protocol.json, selection_frozen.json, ablation.csv, external_holdout.csv, external_training.csv, external_predictions.csv, model_parameters.json, oof_predictions.csv, validation_splits.csv, unit_tests.txt и validation_report.json в results/two_component_v4.
