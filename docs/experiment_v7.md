# Кандидат v7: воспроизведение v6 и проверка представлений молекул

Дата: 07.11.2026. Исходный commit данных: `5eecc1ca55bd7e8a675a0c8939f4c57717e04c41`.

Подготовлен экспериментальный кандидат `submission_candidate_v7.csv`. Его Public MSE пока неизвестна. На повторной локальной scaffold CV фиксированная смесь снизила среднюю MSE на 1.15%; интервал неопределённости включает отсутствие выигрыша. Поэтому подтверждённое улучшение Kaggle не заявляется.

## Воспроизведение исходной модели

Пользователь предоставил `train_v5.py`, `train_v6.py`, `metrics_v6.json` и лучший `submission_v6.csv`. Эти версии исходников восстановлены в `src/`.

`train_v6.py` воспроизвёл исходные метрики: средняя MSE v5 18085334.17363744, v6 17491062.331982985; v6 лучше в 8 из 8 повторов. Совпадают 89 помеченных train-строк, 196 test-строк и 39 внешних подстановок. Максимальное расхождение переносимой реализации с присланным v6 CSV — порядка 1e-11.

Public MSE v6 **9649437.79854** сообщена пользователем; новый score автоматически не получался.

## Проверяемые гипотезы

1. **Смешанная природа целевой колонки требует отдельного моделирования технического кода.** Проверка: прямая регрессия против двухкомпонентных моделей на одинаковых фолдах. Целью соревнования остаётся предоставленная числовая колонка, а не очищенный биологический SI.
2. **Функциональные типы атомов дают другую структуру ошибок, чем обычные Morgan fingerprints.** Проверка: заменить представление только в классификаторе кода, затем сравнить полную замену и фиксированную смесь с v6.
3. **При 320 наблюдениях сильная регуляризация и простые модели снижают риск переобучения.** Проверка: ядровые модели и логистическая регрессия. Графовая сеть с обучением с нуля в этом эксперименте не обучалась; преимущество предобученной сети не предполагается без отдельной проверки.
4. **Полезность внешних наблюдений зависит от совместимости показателей и условий.** Проверка: отдельные абляции источников, внешних весов и преобразований цели. В v7 внешний банк и правила подстановки сохранены из предоставленной v6, а не объявлены новыми проверенными данными.
5. **Выбор log-преобразования должен проверяться по исходной MSE.** Проверка: raw-cap, простое обратное log1p-преобразование, Duan smearing и внутренняя калибровка масштаба.
6. **Оценка зависит от структурной новизны.** Проверка: раздельная CV по обобщённым каркасам и по родительским структурам. Повторяющиеся структуры не пересекают обучающую и валидационную части.

Набор типичных методов — KRR/SVR, леса, бустинг по fingerprints/дескрипторам и графовые модели — описан в [MoleculeNet, Wu et al., 2018](https://pubs.rsc.org/en/content/articlehtml/2018/sc/c7sc02664a). Эта работа обосновывает сравнение методов и структурных разбиений, но не доказывает преимущество конкретной модели на данном наборе.

## Эксперименты

Сначала сравнены 72 конфигурации прямой KRR: несколько радиусов Morgan, count-представления, feature Morgan, atom-pair, torsion, RDKit, MACCS, смеси ядер и четыре alpha. Лучшая фиксированная конфигурация дала MSE 18840687.85 против 19173935.93 у исходной KRR на тех же фолдах. Однако вложенная процедура поиска дала 21302936.09. Этот путь отклонён как основание для обновления модели.

Затем проверены 18 изменений предоставленной v6: варианты регуляризации и ядер классификатора, три логистические регрессии, ансамбль и четыре изменения числового компонента. Подбор выполнен на scaffold-разбиениях с seeds 0–3. Полная замена классификатора на feature-Morgan KRR выбрана до просмотра seeds 101–108.

На дополнительных scaffold-разбиениях полная замена дала MSE 17102642.55 против 17321747.49 у v6, выиграв в 6/8 повторов. Однако на разбиениях по родительским структурам её средняя MSE оказалась выше v6. После этой диагностики выбран консервативный фиксированный ансамбль 50/50. Таким образом, оценка ансамбля на этих повторах является оценкой на использованных при разработке данных, а не слепой независимой проверкой.

## Итоговая конфигурация

Числовой компонент, source-presence flag и внешний lookup соответствуют v6. Альтернативный классификатор использует feature-Morgan radius=2, 8192 бит, хиральность и KRR alpha=0.5. Он обучается на непомеченных исходным source-presence flag train-строках. Для помеченных строк доля кода оценивается с тем же сглаживанием внутри обучающей части.

Финальный прогноз — среднее **двух полных прогнозов после их ограничений v6**, с тем же внешним lookup. Усреднение вероятностей до ограничений было бы другой моделью; это различие проверяется тестом. Меняются 389 из 597 прогнозов; RMSE разности с v6 равна 268.55.

| Проверка | v6 MSE | v7 50/50 MSE | Изменение |
|---|---:|---:|---:|
| Повторная scaffold CV, seeds 101–108 | 17321747.49 | 17121947.96 | −1.15%, 7/8 повторов |
| Повторная parent CV, 4 seeds | 13042986.71 | 13014467.66 | −0.22% |
| Дополнительная scaffold CV, seed 2029 | 17897291.88 | 17832539.41 | −0.36% |
| Дополнительная parent CV, seed 2029 | 13258254.31 | 13248232.58 | −0.08% |

Отдельно проверена вложенная процедура выбора веса из {0, 0.5, 1}: 5 внешних и 3 внутренних фолда. Её MSE **17967076.43** для scaffold и **13522226.55** для parent; обе выше соответствующей v6. Преимущество адаптивного выбора веса не подтверждено.

Для фиксированной смеси среднее изменение MSE на восьми повторах равно −199799.53. Разведочный 95% scaffold-cluster bootstrap интервал по 20000 ресэмплирований: **[−456072.76; 83152.04]**. Группы ресэмплируются целиком, ошибки повторных фолдов сначала усредняются по исходной строке. Интервал включает ноль и не учитывает весь оптимизм поиска. Повторы на тех же 320 строках не создают новые независимые данные.

## Входы и внешние данные

Организаторские признаки: SMILES; цель: SI VACV. Концентрации, их пропуски, Title, strain, Culture и значения из sample submission в обучение не входят. Legacy-загрузчик v5 читает исходные таблицы целиком, но перед новыми кандидатами таблицы сокращаются до разрешённых колонок. Признак присутствия в ChEMBL строится по структуре и замороженным метаданным внешнего источника.

Во всех строгих структурных фолдах внешние обучающие записи с совпадающими таутомерными структурами или каркасами исключаются; внутренние калибровки повторяют исключение. Внешний lookup для совпадающей структуры — отдельный фиксированный источник прогноза, поэтому его метрики сохраняются отдельно от строгой структурной оценки. Разрешение внешних данных нужно сверить с правилами соревнования; публичная страница правил не была доступна из среды. Новые внешние данные в этом запуске не скачивались.

## Дополнительные сведения пользователя

Присланный скриншот Kaggle совпадает со статистикой `data/raw/sample_submit.csv`: 597 строк; mean 509.618904, std 287.778304, min 0.020847, медиана 504.647567, max 999.014685. Это шаблон отправки; его числовая колонка не используется как распределение скрытых test-меток и не обосновывает ограничение прогноза числом 1000.

Присланный SMILES `O=C1N(NC(=O)C2C1C3C4C2C5C3C=CC45)C(=O)C6=CC=C(C=C6)C(F)(F)F` валиден для RDKit, формула C20H15F3N2O3, InChIKey WJVHLYKJTRLKIT-UHFFFAOYSA-N. Он не совпадает с текущими train/test/внешним обучающим банком, в том числе после удаления стереохимии для внешней проверенной таблицы. Если предполагался ST-246/тековиримат, [PubChem CID 16124688](https://pubchem.ncbi.nlm.nih.gov/compound/16124688) содержит другую структуру, формула C19H15F3N2O3. Без измеренной целевой метки присланная структура не добавлялась в обучение. ST-246 уже есть в публикационной внешней таблице, поэтому повтор не расширяет данные.

Приоритет дополнительных источников: первичные публикации с дополнительными таблицами; документация происхождения и кодировки организаторских данных; новые сопоставимые записи ChEMBL; PubChem BioAssay после проверки endpoint/условий. Статус одобренного препарата, EC50 вместо IC50 или измерение по другому вирусу не заменяют нужную метку. Для внешних строк нужны структура, endpoint, значение, единицы, relation, контекст и проверяемый источник.

## Воспроизведение и файлы

Зависимости — исходный `requirements.txt`, CPU. Для небольших матриц рекомендуется один поток BLAS.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python src/train_v6.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python src/train_kernel_v7.py --out results/kernel_v7_reproduced
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python src/experiment_v7.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python src/validate_v7_selection.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python src/train_v7.py --out results/v7_reproduced
python src/predict_v7.py --model results/v7_final/model.joblib --input data/raw/test.csv --out work/repeated_v7.csv
python -m unittest discover -s tests -v
```

`experiment_v7.py` создаёт большие промежуточные world/OOF файлы локально. Они пересоздаются из исходников и не включены в сохранённый компактный набор результатов. `src/validate_v7_artifacts.py` запускается после полного воспроизведения исследования с его стандартными путями.

Сохранены: `results/v7_final/model.joblib`, manifest и хеши входов, `evaluation.json`, `validation_report.json`, попарные OOF-сводки, таблицы кандидатов и вложенных проверок. Для нового прогноза из model.joblib не нужны train/test обучающего эксперимента, внешние CSV или сетевой API; нужны исходные модули и установленное окружение.

Пройдены 17 автоматических тестов, включая независимость классификатора от валидационных меток и точность переносимой формулы. Повторный прогноз из модели совпадает с CSV с максимальным отклонением около 2e-12. Формат итогового CSV: 597 строк, `index,SI VACV`, порядок индексов sample, конечные неотрицательные значения.
