# Отдельный эксперимент: малая примесь до source-presence override

**Рекомендация: оставить α=0.** Вложенная проверка не подтвердила преимущество малой поправки. Production-модели и исходный submission PR #3 не изменены; новый рекомендованный submission с положительным α не сформирован. Подтверждённый пользователем Public MSE PR #3 — **6 327 610,34997**. Public leaderboard не участвовал в выборе α.

Основа — PR #3, commit `b6c2e0c384d043582753993e442be7c042c3139a`, модель `notation_mlm_probability_average`. Эта ветка не включает другие новые архитектуры или обучение на отфильтрованных 237 строках. Все 320 официальных меток сохранены.

Точное вмешательство: из двух исходных logistic-голов непосредственно экспортируются вероятности `predict_proba(scaler.transform(features))` **до** source-подстановки. Для source-present строки применяется `(1−α)*p_group_i + α*p_molecular_i` отдельно к каждой голове, для остальных строк вероятность неизменна. Затем остаются исходные усреднение **50:50**, формула

```text
F(p,r,z) = clip(10000*p + clip(1-p-z,0,1)*r, 0, 10000)
final = clipped_original_lookup_value if lookup_applied else F
```

PR #3 повторяет одну и ту же подстановку у обеих leaf-голов и у paired-обёртки. Повторение исходной жёсткой операции идемпотентно. В эксперименте проверяется точное равенство всех трёх `p_group`; при расхождении выполнение останавливается. Дубликат у обёртки консолидирован с leaf-операциями: α применяется **ровно один раз**. Последовательное смягчение детей и родителя ошибочно давало бы эффективный α². Разные групповые вероятности не усредняются и не подменяются общей.

Зафиксированы исходные компоненты:

- notation logistic C=1, девять исходных признаков записи;
- raw ChemBERTa-MLM logistic C=0.1, 768 frozen mean+CLS признаков; encoder `DeepChem/ChemBERTa-77M-MLM`, revision `ed8a5374f2024ec8da53760af91a33fb8f6a15ff`, batch=1, torch threads=3;
- обе production-головы обучены только на **231 source-absent строке**. Использование их индивидуальных прогнозов для source-present является переносом на исключённую из обучения голов группу;
- исходная формула `p_group=(flagged_training_codes+0.5)/(flagged_training_count+2)`; production p_group=1.5/91=0.01648351648, zero_rate=0.00625;
- прежний centered log1p KRR физической ветви α=3, V/C weights=1, fold-safe Duan smearing; production B_mean=2.997052868762136, B_smear=8.18166717258598;
- прежние source-membership, lookup, коэффициенты ансамбля и все ограничения прогноза. Старые v7 головы вычисляются исходным portable-кодом, но имеют вес **0** в выбранном кандидате.

SHA256 исходных моделей и всех используемых файлов, коэффициентов/scalers голов, физического dual, source-membership и lookup находятся в `baseline_frozen.json`. Основная модель: `f58b880b834cf9bb118f7559ba7533e20933329446b781764b3919ad4d3b07c1`; v7 bundle: `43a1565e3dc2aec5b8c340fb2f4fd02d3032d25b39e75c3c2ed0dcc68d9eed5b`. Хеши повторно проверены после эксперимента.

Ранее неудачный `gate_followup` переобучал MLM logistic на **всех** строках с/без source-feature, причём проверял другую композицию голов. Он не равнозначен снятию override при неизменных весах. Поэтому α=1 здесь воспроизведён отдельно как диагностический контроль **замороженных голов**, не включённый в поиск малой поправки.

Эти 157 строк представляют **145 tautomer structures и 74 generic scaffolds**. При α=0.025/0.05/0.10/0.20 максимум изменения SI составляет 223.51/447.03/894.05/1788.11. Все 39 lookup-строк и все source-absent строки неизменны. На фактических production-компонентах clipping не скрывает дополнительного эффекта: верхняя численная граница не активируется. В рекомендуемом режиме α=0 изменённых test-строк **нет**.

Выполнен **режим Б: вложенная проверка процедуры**, поскольку новых независимых calibration/evaluation-данных нет. Production-веса заморожены и используются только для анализа финального inference. Для CV обучены отдельные копии компонентов со строго фиксированными настройками PR #3; для каждого α веса соответствующей копии одинаковы. Головы не переобучаются специально ради экспорта individual probability.

Основная проверка читает фактические пять архивных scaffold-фолдов `results/v2/validation_splits.csv`. Внутри каждого outer-train строятся три внутренних scaffold-фолда, seed314. По общей невзвешенной конечной MSE всех внутренних строк выбирается единственный общий α из **{0, 0.025, 0.05, 0.10, 0.20}**. При равенстве выбирается меньший α. Если затронуто менее двух независимых структур или каркасов — α=0. Внешние numerical SI проверочных структур и каркасов исключаются на обоих уровнях. Замороженный публичный source-membership вычисляется из SMILES и не использует organizer-концентрации.

Lookup в OOF выключен, как в исходной проверке PR #3: внешние совпадения held-out структур исключены из обучения. Наличие кандидата в полной lookup-таблице сохраняется только как диагностический столбец и не участвует в прогнозе. Production lookup применяется последним без изменений. Таким образом, исходное различие CV/production lookup не устраняется и не маскируется новой абляцией.

Основные outer-фолды выбрали α **[0, 0.05, 0.10, 0.10, 0]**. При фиксированном положительном α потенциально затрагиваются 89/320 строк, 87 структур и 41 scaffold; при реально выбранных outer-α изменились **60 строк, 59 структур и 22 scaffold**. Ошибка малых SI≤100 выросла с 3 856 494,79 до 3 882 714,65; физического хвоста SI>1000 — с 186 059 538,17 до 186 182 566,17. Ошибка технических 10000 не изменилась: единственная source-present кодовая строка оказалась во фолде с выбранным α=0. Метрики остальных групп и каждого фолда опубликованы отдельно.

Диагностический фиксированный α=0.1 дал MSE **11 331 250,11**, примерно −0.086%. Однако строка CSV **175** одна дала +39 264,94 единицы вклада в уменьшение MSE при общем уменьшении всего 9760,91 — **402,27% чистого выигрыша**. Без этой строки суммарный эффект отрицательный: MSE-вклад −29 504,03. Для экстремума 36 066,667 фиксированный α=0.1 снизил прогноз с 331.20 до 319.49. Выбирать α=0.1 по этой таблице и объявлять независимый выигрыш нельзя.

Полное снятие подстановки у тех же голов, α=1, дало диагностическую MSE **12 215 836,22**, хуже на **7,71%**. Полная трёхфолдовая calibration на всех 320 строках выбрала α=0.1, но это обучающий выбор параметра, а не новая оценка качества; из-за отрицательной вложенной оценки рекомендованный α остался **0**.

Парный bootstrap по 117 scaffold-группам, 2000 повторов seed7519, дал 95% интервал уменьшения MSE **[−32 965,73; −9884,01]**. Это условная оценка на уже исследованной выборке, не гарантия популяционного эффекта. Повторные разбиения используют те же 320 молекул и не являются независимыми новыми данными. Преимущество поправки не подтверждено ни основной проверкой, ни повторами.

Обязательные проверки выполнены. **15 unit tests прошли**: α=0/1, выпуклая интерполяция, отсутствие эффекта α², неизменность source-absent и lookup-строк, clipping/zero_rate, конечность, ID и порядок, отказ при несовпадении group probability, fallback при недостатке групп. Исходный production α=0 воспроизведён до **6.37e−12**. Для внешнего фолда с исходным выбранным α=0.05 все внутренние модели и внешний прогноз пересчитаны в пустых кэшах после замены внешних y на NaN и 1e12: выбранный α не изменился, отклонение прогнозов не более **9.10e−13**. Настоящий CLI на всех 597 строках с чистыми/испорченными запрещёнными колонками и обратным порядком даёт отклонение от PR #3 не более **7.28e−12**. Дополнительный CLI-контроль α=0.1 на восьми строках трёх типов также прошёл. Все production/data/source SHA256 неизменны.
