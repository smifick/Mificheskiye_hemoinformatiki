# Технический отчёт

# Регрессия индекса селективности соединений в отношении VACV

Дата фиксации результатов: 6 ноября 2026 года.

Идентификатор эксперимента: results/final_run.

Репозиторий: https://github.com/smifick/Mificheskiye_hemoinformatiki

## 1. Постановка задачи

Задача заключается в предсказании числовой целевой переменной SI VACV по SMILES-записи молекулы. Биологический индекс селективности определяется отношением CC50/IC50. Соревновательная оценка использует среднюю квадратичную ошибку: MSE = mean((y − prediction)²). В модель подаются только признаки, вычисленные из структуры.

В предоставленной целевой колонке измеренные отношения объединены с техническими кодами отсутствующих данных. Поэтому качество предсказания соревновательной метки и качество оценки биологического SI рассматриваются отдельно.

## 2. Исходные данные и аудит цели

Обучающая таблица содержит 320 строк, тестовая — 597. Шаблон submission включает index и SI VACV. Все исходные SMILES разобраны RDKit. В train выявлено 13 многокомпонентных записей; после стандартизации остаются 312 различных родительских структур. В test — 570 родительских структур. Общих родительских структур между train и test — 30.

Структура целевых значений:

Категория | Строк | Интерпретация

Обе концентрации доступны | 237 | SI согласуется с CC50/IC50 с относительным допуском 2%

Код 10000 не является измеренным значением SI, нижней границей или показателем неактивности. Значение неизвестного IC50 не восстанавливается по этому коду. Отсутствие измерения само по себе не характеризует активность соединения.

Повторные записи сохранены как отдельные наблюдения, поскольку они могут относиться к различным экспериментальным условиям. У одинаковых структур встречаются противоречивые метки. При локальном разделении такие записи принадлежат одной scaffold-группе.

В фактическом обучающем наборе сохранены все 320 организаторских строк, исходные поля, каноническая структура, scaffold-группа, номер строки и флаг технического значения. Отдельно подготовлен поднабор из 237 строк с доступными концентрациями. Он предназначен для последующего анализа биологического SI; текущая модель на нём отдельно не обучалась. DOI организаторских записей не предоставлены.

## 3. Стандартизация и признаки

Стандартизация включает разбор SMILES, выбор крупнейшего углеродсодержащего компонента, обработку RDKit Uncharger и формирование канонического изомерического SMILES. Исходная запись сохраняется. Таутомерная нормализация не применяется; выбранная политика не гарантирует объединения всех химически эквивалентных записей.

Основные признаки — Morgan fingerprints радиуса 2, длиной 2048 бит, с учётом хиральности. Для дополнительных моделей рассчитаны 217 дескрипторов RDKit. Заполнение пропусков и масштабирование входят в модельный pipeline и обучаются внутри соответствующего фолда.

Выбранная Kernel Ridge-модель использует только Morgan fingerprints. IC50, CC50, названия соединений, культура и штамм в признаки не входят.

## 4. Схема валидации

Группы сформированы по обобщённым каркасам Bemis–Murcko; всего получено 117 групп. Ациклические структуры объединены в одну группу. Внешнее разделение с seed=42 выделяет 20% групп: 268 обучающих строк и 52 отложенные. Размеры долей по строкам определяются распределением каркасов.

На 268 строках применяется GroupKFold из пяти фолдов. Модель выбирается по MSE объединённых out-of-fold прогнозов. Для каждого фолда контролируется отсутствие пересечения scaffold-групп. Схема ограничивает структурную утечку, но не исключает всякое химическое сходство между группами.

Сравнены 16 конфигураций: константные прогнозы, Random Forest, Extra Trees, Histogram Gradient Boosting, Ridge и Kernel Ridge с Tanimoto-ядром. Проверены исходная и log1p-шкала цели; для Kernel Ridge — alpha 0.1, 1 и 10. Полный список параметров зафиксирован в исходном коде.

Выбранная конфигурация оценена на отложенной части один раз. После этого выполнено обучение на всех 320 строках для итогового submission. Таким образом, модель для оценки и модель для тестовых прогнозов имеют одинаковую конфигурацию, но разный объём обучающих данных.

## 5. Выбранная модель

Выбрана Kernel Ridge Regression с ядром Tanimoto и alpha=1 в исходной шкале SI. Для бинарных отпечатков сходство задаётся отношением числа общих активных битов к числу активных битов в их объединении. Матрица ядра строится только между структурами соответствующих обучающей и прогнозируемой частей.

Финальные прогнозы ограничены снизу нулём. Верхнее ограничение не используется. Записи с большими SI не исключаются на основании одной величины целевой переменной.

## 7. Анализ ошибок

| Категория отложенных меток | Строк | Средняя метка | Средний прогноз | Доля суммы квадратов ошибок |

Категория отложенных меток | Строк | Средняя метка | Средний прогноз | Доля суммы квадратов ошибок

Код отсутствующего IC50 | 13 | 10000.00 | 4918.26 | 55.8%

Обе концентрации доступны | 39 | 127.06 | 2088.39 | 44.2%

Наблюдается смещение прогнозов в сторону промежуточных значений между обычными отношениями и техническим кодом. Для записи с SI=5.111 получен прогноз 6666.17. Пять крупнейших ошибок дают 36.2% суммы квадратов ошибок отложенной выборки.

Во внутренней CV одна запись с SI=36066.667 даёт 22.2% суммарной квадратичной ошибки. Она не исключается автоматически: наличие больших значений само по себе не доказывает ошибку данных.

Для MSE усреднение по возможным исходам может быть оптимальным при неопределённости, поэтому пороговая замена промежуточных прогнозов на 0 или 10000 не гарантирует улучшения. Перспективный, пока не проверенный эксперимент — отдельно оценивать вероятность технического кода и условное распределение SI при наличии измерений. Прогноз факта отсутствия измерения по одной структуре ограничен зависимостью пропусков от источника и протокола эксперимента.

Отложенная выборка исследована после первоначальной оценки. Последующий подбор по её ошибкам потребует новой независимой проверки; дальнейшее улучшение по этому анализу пока не заявляется.

## 8. Выгрузка внешних данных

Источник — ChEMBL REST API: https://www.ebi.ac.uk/chembl/api/data/ . По assay_organism, содержащему Vaccinia, найден 621 анализ, включая 588 функциональных. Endpoint-записи запрашиваются по идентификаторам анализов; CC50 дополнительно собираются из соответствующих публикаций. Документы запрашиваются отдельно для DOI и библиографической атрибуции.

Итоговый набор содержит 6510 уникальных endpoint-записей с DOI:

CC50 из общей публикации может относиться к другим клеточным системам и экспериментальным задачам. Наличие общего DOI не гарантирует сопоставимости измерений.

Концентрации приводятся к мкМ только из распознаваемых молярных единиц. EC50 сохраняется отдельным endpoint и не переименовывается в IC50. Значения с операторами > и < остаются границами и не используются как точные метки. Проверяются числовое значение, SMILES, комментарии валидности ChEMBL и флаг потенциального дубликата.

2647 записей прошли технические проверки endpoint. Это не подтверждает сопоставимость биологических условий. Найдены 337 предварительных пар для одного ChEMBL-соединения и публикации: 152 пары с IC50 и 185 с EC50. Все требуют проверки контекста; в обучение они не включены. Два прямых точных значения SI равны 0 и также требуют проверки первоисточника; два других значения представлены нижними границами >52 и >750.

Ссылки на записи, DOI, описания анализов, клеточные линии и статусы проверки сохранены в таблицах. В manifest включены URL и SHA256 ответов 44 API-запросов. Условия использования ChEMBL: https://chembl.gitbook.io/chembl-interface-documentation/about/terms-of-use .

## 9. Проверки и воспроизводимость

Проверены схема submission, 597 строк, порядок index относительно шаблона, конечность и неотрицательность прогнозов. Загруженная модель воспроизводит submission с допуском 1e-12. Проверено отсутствие пересечения scaffold-групп во внешнем разделении и внутренних фолдах, формат DOI и арифметика предварительных отношений концентраций.

Пять модульных тестов проверяют стандартизацию соли, группировку стереоизомеров, обработку ошибочного SMILES, инварианты Tanimoto-ядра и разбор числовых значений/времени измерения. Техническая валидация не заменяет проверку первичных публикаций.

Окружение: Python 3.12; точные версии закреплены в requirements.txt. В config.json сохранены параметры, версии библиотек и SHA256 входных CSV. Команды расчёта приведены в docs/reproducibility.md. Отчёт DOCX формируется из данного Markdown командой python src/make_report.py --root . .

## 10. Ограничения и дальнейшие эксперименты

Основное ограничение — неоднородная семантика целевой колонки: измеренные отношения, код пропуска IC50 и нули при отсутствующем CC50. Научная модель биологического SI требует отдельной постановки на строках с подтверждёнными концентрациями и проверенных внешних измерениях.

Дополнительные ограничения: малый объём выборки, неоднородные культуры и штаммы, повторные структуры с разными метками, отсутствие DOI исходных организаторских записей и неполные метаданные внешних анализов. Tanimoto-сходство с ближайшей обучающей структурой используется как диагностика структурной близости; калиброванная неопределённость не оценивалась.

Предсказание SI в клеточном эксперименте не устанавливает клиническую эффективность или безопасность соединения. Результаты предназначены для последующей экспериментальной проверки.

## 11. Дополнительные эксперименты v2

Проверена процедура выбора из 21 конфигурации на вложенной групповой валидации. На одинаковых внешних структурных фолдах MSE исходной конфигурации составила 19173935.93, вложенной процедуры выбора — 19617182.66. Устойчивое преимущество не подтверждено. Лучший фиксированный ансамбль, выбранный по OOF-прогнозам, получил MSE 19041223.06; снижение на 0.69% подвержено оптимизму отбора.

Подготовлен экспериментальный submission_candidate_v2.csv для дополнительной внешней проверки. Его результат Kaggle неизвестен. Входы по-прежнему ограничены SMILES; пропуски концентраций используются только как вспомогательные обучающие цели. Дополнительные интерполяционные и SVM/центрированные-kernel сравнения не превзошли исходную конфигурацию. Подробный протокол и отрицательные результаты приведены в docs/experiment_v2.md.

## 12. Публикационная верификация и v3

Сверены 56 пар из двух публикаций с контролем клеточной линии и авторского определения SI. Равенство времени измерений не считается обязательным при явно определённой авторами паре. Проверены исключение внешних совпадений с test и отсутствие валидационных каркасов в дополнении.

Входы v3: только SMILES и целевая метка. Канонизация таутомеров уменьшила MSE на одинаковых scaffold-фолдах с 19173935.93 до 18888578.92. Внешнее дополнение в испытанных вариантах не выбрано. Public MSE v3 неизвестна. Подробные первоисточники, проверенные таблицы и абляции приведены в docs/research_external_v3.md.

## 13. Двухкомпонентный эксперимент v4

Обучены классификатор технической метки с групповой sigmoid-калибровкой и KRR физического SI с внешними весами 0/0.1/0.3/1. Для log-цели поправка в исходную шкалу оценивается только по внутренним OOF-прогнозам обучающей части. Выбранная смесь дала MSE 20038362.56, baseline на тех же фолдах — 18888578.92; улучшение не получено.

Отдельная ретроспективная проверка физического компонента выполнена на 19 структурах публикации, исключённых из organizer-train/test и внешнего обучения. Внешнее обучение содержит две Vero-записи; проверочные метрики не использовались при выборе. Источники уже изучались в прежних экспериментах, поэтому оценка не является полностью новым перспективным тестом. Подробности: docs/two_component_v4.md.
