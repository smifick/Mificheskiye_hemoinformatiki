01. Прочитаны train.csv (320 строк), test.csv (597 строк), sample_submit.csv (597 строк). Проверены схема, цель и порядок идентификаторов.
02. Выбрана цель SI VACV и проверены конечность и неотрицательность меток. Признаки получаются только из SMILES; CC50, IC50, название, культура и штамм не используются.
03. Проверены все SMILES: ошибочных строк нет. Для 13 многокомпонентных обучающих записей выбрана наиболее крупная углеродсодержащая часть; выполнена нейтрализация зарядов RDKit Uncharger. Исходный SMILES сохранён.
04. После стандартизации в train осталось 312 разных родительских структур. Строки повторов сохранены из-за разных экспериментальных условий, но всегда относятся к одной scaffold-группе.
05. Выявлено 81 значение SI=10000, каждое совпадает с пропуском IC50. Пользователь подтвердил: это служебный код отсутствующего IC50. Метки сохранены для воспроизведения задания Kaggle; это не доказанные значения селективности.
06. Для 237 записей доступны IC50 и CC50; отношение совпадает с SI с относительным допуском 2%. Пропущенные исходные концентрации не восстановлены вымышленными значениями.
07. Построены Morgan fingerprints: радиус 2, 2048 бит, с учётом хиральности. Для части сравниваемых моделей рассчитаны дескрипторы RDKit. Пропуски дескрипторов заполняются только внутри обучающего фолда.
08. Построены 117 обобщённых каркасов Bemis–Murcko. Ациклические соединения объединены в одну группу. Разбиение удерживает связанные структуры в одном фолде; оно не гарантирует полного отсутствия структурного сходства между группами.
09. Отделена отложенная выборка: 52 строк; оставшиеся 268 строк использованы во внутренней GroupKFold-валидации из пяти фолдов. Seed=42.
10. Сравнены 16 конфигураций: константные прогнозы, Random Forest, Extra Trees, Histogram Gradient Boosting, Ridge и Kernel Ridge с Tanimoto-ядром, включая исходную и log1p-шкалу цели.
11. По объединённым out-of-fold предсказаниям внутренней CV выбран tanimoto_krr_1_raw. Выбор выполнен по MSE без использования holdout. Гиперпараметр alpha=1.
12. Выбранная модель оценена на holdout один раз. После оценки она переобучена на всех 320 строках для финального submission; оценочная и финальная модели имеют разный объём обучающих данных.
13. Предсказания обрезаны снизу нулём; после этого проверены конечность, две колонки index и SI VACV, 597 строк и порядок индексов из шаблона.
14. Сохранён model.joblib и написан отдельный predict.py. Повторный прогноз из сохранённой модели совпал с submission с допуском 1e-12.
15. Выполнена выгрузка ChEMBL: 621 анализ; 6510 уникальных endpoint-записей, все с DOI. Записаны URL и SHA256 ответов API.
16. CC50 дополнительно запрашивался по публикациям с VACV-активностью. Такие CC50 не являются отдельными противовирусными измерениями; контекст сохранён в таблице.
17. Концентрации переведены в мкМ только из распознаваемых молярных единиц. Значения с > или < сохранены с оператором, но не считаются точными метками. EC50 не переименовывается в IC50.
18. Сформированы 337 возможных пар концентраций в одной публикации для одного ChEMBL-соединения: 152 пары с IC50 и 185 с EC50. Каждая имеет рассчитанное отношение и статус проверки контекста.
19. Для всех найденных пар контекст/время эксперимента не подтверждены достаточно полно. Отношения сохранены как предварительные кандидаты, без автоматического допуска в обучение. Два прямых точных SI из ChEMBL равны 0 и также требуют проверки первоисточника.
20. Финальный обучающий набор состоит из предоставленных 320 строк; внешние метки не добавлялись. Файл training_dataset.csv содержит SMILES, IC50_uM, CC50_uM, SI, doi, исходные поля и флаги. DOI организаторских записей отсутствуют и оставлены пустыми.
21. Проверены независимые инварианты: отсутствие пересечения scaffold-групп, схема submission, единицы/отношения внешних записей, формат DOI, точность вычисления отношений.
22. Запущены пять модульных тестов: нормализация солей, группировка стереоизомеров, ошибочный SMILES, свойства Tanimoto-ядра, проверка числовых значений и времени.
23. Подготовлены README, исходный код, внешняя база, фактический обучающий набор, модель, метрики и пояснительный документ для размещения в GitHub.
