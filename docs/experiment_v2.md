# Дополнительные эксперименты: кандидат v2

## Статус

Подготовлен `submission_candidate_v2.csv`: 597 прогнозов, колонки `index,SI VACV`. Это экспериментальный кандидат для внешней проверки. Public MSE кандидата пока неизвестна. Устойчивое преимущество над первой моделью локально не подтверждено; замена первой модели как основного результата не заявляется.

## Сравнение на одинаковых структурных фолдах

Внешнее разделение: GroupKFold из пяти фолдов по обобщённым каркасам, shuffle=True, random_state=2718. Внутреннее сравнение: три групповых фолда, random_state=314. Данные: все 320 обучающих строк. Тестовые концентрации и метки в признаки и выбор модели не входят.

| Оценка | MSE |
|---|---:|
| Первая конфигурация: KRR Tanimoto, alpha=1, те же внешние фолды | 19173935.93 |
| Вложенная процедура выбора из 21 конфигурации | 19617182.66 |
| Лучший фиксированный кандидат, выбранный по этим OOF-прогнозам | 19041223.06 |

Преимущество лучшего фиксированного кандидата на использованных для выбора OOF-прогнозах составляет 0.69%. Эта оценка подвержена оптимизму отбора. Вложенная процедура выбора дала MSE на 2.31% выше первой конфигурации. Такие результаты не дают оснований обещать рост позиции Kaggle.

Внешние фолды данного эксперимента отличаются от первоначального отложенного разделения 268/52. Сравнивать величины MSE между этими схемами как прямое улучшение нельзя.

## Состав кандидата

Финальный прогноз — среднее двух компонентов:

1. KRR с Tanimoto-ядром по Morgan fingerprints радиуса 2, alpha=1, исходная шкала цели.
2. Модель кодировки пропусков и условного SI. Kernel Ridge alpha=0.3 предсказывает три вспомогательных состояния: известны обе концентрации; отсутствует IC50; отсутствует CC50. Вспомогательные цели определяются только на обучающей таблице. Ядро — среднее Tanimoto по Morgan радиусов 2 и 3 и RDKit fingerprints. После нормализации выходы трактуются как веса состояний. Условный числовой SI оценивает Extra Trees по log1p(SI) на 237 строках с обеими концентрациями. Прогноз кодированной метки: 10000*p_missing_IC50 + p_observed*conditional_SI.

Веса состояний не являются калиброванными вероятностями биологической активности. Пропуск IC50 не означает неактивности, а код 10000 не является измеренным SI. Все входные признаки вычисляются только из SMILES. Внешние данные в обучение не включались.

## Дополнительные отрицательные результаты

`results/interpolation_v2/` содержит сравнение 30 вариантов KRR и ближайших соседей. Разбиение группирует родительские структуры без учёта стереохимии; точные родительские повторы не пересекают фолды. Лучшей осталась исходная конфигурация: MSE 14636331.23. Режим учитывает интерполяцию между структурами знакомых каркасов; 75.0% test-строк имеют каркас, присутствующий в train. Медианное максимальное сходство Morgan: 0.660 на этих валидационных фолдах и 0.705 в test.

`results/calibrated_v2/` содержит дополнительное сравнение 23 конфигураций: центрирование ядра с интерсептом и SVM-модели вспомогательного состояния с условной регрессией SI. По структурной OOF MSE лучшей также осталась исходная конфигурация.

Отрицательные результаты сохранены вместе с метриками. Новые конфигурации не отбирались по ответам Kaggle.

## Воспроизведение

```bash
python src/train_v2.py --root . --out results/v2_reproduced
python src/train_interpolation.py --root . --out results/interpolation_reproduced
python src/calibration_benchmark.py --root .
python src/predict_v2.py --model results/v2/model_v2.joblib --input data/raw/test.csv --out results/repeated_v2.csv
```

Для обучения необходимы версии из requirements.txt, включая CatBoost 1.2.10. Каталог результата должен отсутствовать до запуска. `calibration_benchmark.py` использует сохранённые обучающие признаки `results/v2/model_v2.joblib`; его выходной каталог — `results/calibrated_v2`. Для повторного запуска в чистом checkout сохранённые результаты предварительно переносятся в другой каталог.
