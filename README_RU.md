# Этап 1: RDKit + Morgan fingerprints + baseline

Статус: код подготовлен и проверен техническим запуском. Исходный датасет VACV и библиотека кандидатов не предоставлены. Обученной модели VACV, научных метрик и прогнозов кандидатов в этом архиве нет.

## Установка и запуск

Нужен Python 3.12. Создайте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python stage1.py --data data.csv --smiles-col SMILES --target EC50_uM --transform log10 --out runs/ec50_001
```

В Windows активируйте `.venv\Scripts\activate`.
Путь `--out` должен быть новым: существующие эксперименты не перезаписываются.
Для SI используйте `--target SI --transform log10`. Для CC50 — `--target CC50_uM --transform log10`.
Каждая цель обучается отдельным запуском. Бинарные метки требуют другого режима; этот baseline решает регрессию.

Для прогнозирования заданной библиотеки добавьте `--library library.csv`. Столбец SMILES должен называться так же, как в обучающей таблице.

## Перед запуском на настоящих данных

1. Используйте числовой endpoint в одинаковых единицах и сопоставимых условиях эксперимента. Не смешивайте клеточные линии, штаммы, протоколы и длительности без проверки.
2. Убедитесь, что строки не имеют отдельных операторов цензурирования: например, столбец value=100 и relation='>' нельзя подавать как точное значение. Строковые '>100' скрипт исключит и запишет в rejected.csv.
3. Для EC50 меньший прогноз соответствует более высокой активности; для CC50 и SI больший — предпочтительнее в рамках соответствующего анализа.
4. При log10 метрики и prediction находятся в логарифмической шкале. Возврат в исходные единицы: 10 ** prediction.
5. По SI нельзя доказать отсутствие воздействия на другие объекты организма.

## Что делает код

- Проверяет SMILES через RDKit; исключает пустые, ошибочные и многокомпонентные записи. Соли не преобразуются автоматически: требуется отдельное согласованное правило.
- Канонизирует SMILES с сохранением стереохимии. Не выполняет унификацию таутомеров и зарядов; это ограничение нужно проверить на реальном датасете.
- Объединяет точные повторы по медиане исходных значений; сохраняет число измерений, минимум, максимум и номера исходных строк. Не объединяйте несопоставимые эксперименты.
- Строит Morgan radius=2, 2048 бит.
- Группирует по обобщённому каркасу Bemis–Murcko; все ациклические структуры объединяет в одну группу. Размер holdout приблизителен: 20% групп, а не обязательно молекул.
- Требует минимум 20 структур и 5 групп. Это технический минимум, а не гарантия достаточности данных.
- Выделяет holdout с seed=42 и проводит GroupKFold только на train.
- Сравнивает DummyRegressor (медиана) и RandomForestRegressor (300 деревьев, min_samples_leaf=2). Выбирает модель по среднему MAE в CV; гиперпараметры не подбираются по holdout.
- Сохраняет выбранную модель, обученную только на train. Holdout оценивается один раз; refit на всём датасете не выполняется.
- Выдаёт первые прогнозы для holdout и, при наличии библиотеки, для неё. Не составляет shortlist автоматически.

## Результаты реального запуска

config.json — параметры, версии и SHA256 входной таблицы.
rejected.csv / accepted_records.csv — аудит строк.
cleaned.csv — уникальные структуры, агрегированные цели, каркасы.
fingerprints.npz — матрица признаков и SMILES.
split.csv — train/test принадлежность.
cv_metrics.csv / cv_predictions.csv — метрики и предсказания внутренних фолдов.
metrics.json / test_predictions.csv — оценка holdout и первые прогнозы.
model_train_only.joblib — выбранная модель и конфигурация; загружать только доверенные joblib-файлы.
library_predictions.csv / library_rejected.csv — результаты для необязательной библиотеки.

Из-за структурной новизны прогнозы могут быть ненадёжны; количественная оценка неопределённости и области применимости в этап 1 не включена. Scaffold-разбиение уменьшает структурную утечку, но не гарантирует её полного отсутствия.

## Проверка кода

Полный запуск выполнен на искусственных структурах с условной числовой целью, не связанной с VACV. Проверены исключение ошибочного SMILES, многокомпонентной записи, неточного значения, объединение дубликата, размер fingerprints, непересечение scaffold-групп, CV, сохранение модели и прогнозы библиотеки. Биологическое качество этим не проверяется.
