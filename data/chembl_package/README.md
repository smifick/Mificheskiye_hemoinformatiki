# Данные для регрессии SMILES → SI VACV

## Файлы для обучения

- training/vacv_si_vero.csv: 38 строк с положительными точными SI для клеточной линии Vero.
- training/vacv_si_all_cells.csv: 56 строк (Vero: 38, A549: 18), 38 ChEMBL-молекул, две публикации.

Вход модели — SMILES, целевая колонка — SI. SI_definition = CC50/IC50.
IC50_uM и CC50_uM измерены в микромолях/литр. Концентрации не следует
использовать как признаки при оценке задачи прогнозирования только по SMILES:
они непосредственно определяют целевое отношение.

Для первого опыта по одной клеточной линии используйте vacv_si_vero.csv.
В общей таблице одна молекула может иметь разные SI для разных клеточных линий.
Одних SMILES недостаточно, чтобы различить эти условия. Усреднение разных
клеточных линий автоматически не выполнялось.

Метки взяты из уже существующей публикационной проверки в репозитории:
https://github.com/smifick/Mificheskiye_hemoinformatiki/tree/ffc18f28f1e3bef0acba959098d47ce694697918/data/external_curated
В этой проверке концентрации сопоставлялись с таблицами публикаций, клеточной
линией и молекулой в ChEMBL. Структуры приписаны через ChEMBL и числовое
сопоставление; независимая проверка изображений структур не выполнялась.
Для этого архива все 56 пар повторно сопоставлены с текущей выгрузкой по ID,
клеточной линии, публикации, единицам, точности и допустимости измерений.
Концентрации из авторских таблиц и ChEMBL сверены с допуском 1.5%.

SI рассчитан из табличных концентраций. SI_reported сохраняет авторское
округлённое значение. DOI, URL, ID измерений, таблица и статус проверки
сохранены построчно. Пустые значения не заменялись техническими кодами.

## Исходная выгрузка

chembl_export/ содержит результат парсинга ChEMBL 37:
6853 уникальных измерения, включая 2182 измерения из подтверждённых VACV-анализов,
218 измерений с неоднозначной привязкой и 4453 дополнительных CC50 из публикаций.

- external_endpoints.csv: полные измерения с метаданными и статусами.
- collected_database.csv: компактная таблица измерений.
- candidate_si_pairs.csv: 329 предварительных пар (152 CC50/IC50, 177 CC50/EC50).
- external_si_database.csv: 152 предварительные пары CC50/IC50.
- review_required_endpoints.csv: измерения из неоднозначных анализов.
- assay_search_audit.csv: журнал отбора анализов.
- raw_activities.json, all_assays.json, documents.json, targets.json: исходные сведения API.
- request_manifest.json: URL, SHA256 ответов и время загрузки.
- collection_summary.json и chembl_status.json: статистика и версия базы.

Все 6853 измерения не являются готовыми обучающими метками SI. Значения с
операторами > или < остаются границами. valid_endpoint означает техническую
допустимость отдельного измерения. Предварительные пары требуют проверки
сопоставимости условий и определения SI. Они не добавлены к training/.
direct_si.csv содержит только заголовок: положительных точных прямых SI
из автоматически подтверждённых анализов в этой выгрузке не найдено.

## Разделение выборки и MSE

canonical_smiles и scaffold_group рассчитаны способом, используемым в
src/train_model.py исходного репозитория. Разделяйте данные по scaffold_group,
чтобы одинаковые и близкие каркасы не попадали одновременно в обучение и оценку.
При работе с общей таблицей все измерения одной молекулы держите в одной части.
Малый размер набора и всего две публикации ограничивают устойчивость оценки.

Пример чтения:

    import pandas as pd
    d = pd.read_csv('training/vacv_si_vero.csv')
    smiles = d['SMILES']
    y = d['SI']
    groups = d['scaffold_group']

MSE считается по истинным SI и предсказаниям для отложенных строк:

    from sklearn.metrics import mean_squared_error
    mse = mean_squared_error(y_test, predictions)

MSE по исходному SI и MSE по логарифму SI — разные метрики.

## Происхождение и контроль

reviewed_sources/ сохраняет исходную проверенную таблицу и журнал её
сопоставления с публикациями. provenance/ содержит состав пакета и проверки.
FILES_SHA256.json содержит контрольные суммы всех файлов архива, кроме себя.
