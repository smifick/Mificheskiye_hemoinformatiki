# Пилот Europe PMC: проверенные числовые таблицы SI

Источник обучающих фактов: **Cardiac glycosides inhibit early and late vaccinia virus protein expression**, DOI [10.1099/jgv.0.001971](https://doi.org/10.1099/jgv.0.001971), [PMC10995631, таблица 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC10995631/#T2). Публикация доступна по **CC BY 4.0**. Атрибуция и выбранные числовые колонки сохранены в `PMC10995631_table_evidence.xml`; полный текст и лабораторные процедуры не экспортируются.

|---|---:|
| Библиографические OA-результаты запроса Europe PMC | 138 |
| Полностью проверенный новый источник | 1 |
| Отдельные IC50/CC50 | 24 |

| Пары с однозначным структурным идентификатором | 12 |
| Структуры в новом SI-наборе | 12 |
| Новые структуры относительно всех прежних таблиц проекта | 8 |
| Scaffolds в новом SI-наборе | 6 |
| Scaffolds, новые относительно train/test организаторов | 6 |
| Scaffolds, новые относительно всего прежнего проекта | 3 |

Четыре структуры уже встречались в старой таблице отдельных endpoint, однако новая публикация и измерения отсутствовали. Они не объявляются новыми молекулами. Все 12 измеренных отношений — дополнительные экспериментальные наблюдения, а не случайные записи SMILES, псевдометки или технические коды 10000.

Для каждой строки проверена цепочка **точное имя в таблице → единственный PubChem CID → точный синоним CID → SMILES → совпадающий InChIKey**. При множественном CID или приблизительном имени строка автоматически не принимается. Стереохимия исходной структуры сохраняется; parent/tautomer и generic Bemis–Murcko применяются отдельно для аудита пересечений. Идентичность партии и стереохимическая чистота авторского образца независимо не установлены.

В таблице концентрации даны в nM, они переведены в µM. `SI` рассчитан из опубликованной пары, `SI_reported` сохраняет округлённый авторский индекс. Допуск согласования — 3%. Нули, отсутствующие значения и границы не становятся точными SI. Endpoint — клеточный VACV IC50, а не EC50 или молекулярное связывание. **Контекст численных кривых таблицы 2 / рисунка 1 — HeLa**. В той же работе встречается другая линия A-RPE-19, относящаяся к другим анализам: её нельзя переносить на эти метки. Указание штамма — Western Reserve; метаданные не являются признаками модели.

`training_si.csv` исключает все структуры official test до передачи в обучение. Затем код обучения обязан для каждого фолда исключить внешние структуры и каркасы его проверочной части. `verified_si.csv` хранит научные факты отдельно от допуска в обучение. Сравнение с другими базами выполняется по parent, DOI и происхождению; здесь не найдено повторных копий той же пары.

Дополнительный отрицательный пилот: [PMC9533862](https://pmc.ncbi.nlm.nih.gov/articles/PMC9533862/), DOI 10.1016/j.antiviral.2010.10.001. В выбранной таблице восемь строк, шесть потенциально точных пар; две строки имеют границы. **Обучающих меток из этого источника не создано**: источник имеет условное разрешение Elsevier на исследовательское повторное использование, а не бессрочную CC BY; актуальность разрешения и точные химические формы в этом ограниченном пилоте не установлены. Запись сохранена в `negative_pilot_summary.json`; она не объявляется шестью проверенными SI.

Запрос из библиографического поиска использует title/abstract и OA-фильтр; 138 результатов не означают 138 проверенных работ и не доказывают полноту мировой литературы. В этой итерации выполнена ограниченная проверка выбранных первичных таблиц. `source_registry.csv` различает проверенный источник и отрицательный пилот.

Основные файлы:

- `measurements.csv` — отдельные числовые endpoint и операторы.
- `table_rows.csv` — исходные выбранные ячейки, только необходимые колонки.
- `structure_map.csv` — однозначные идентификаторы и URL структуры.
- `verified_si.csv`, `training_si.csv` — научные факты и допустимый банк обучения.
- `excluded_si.csv`, `review.csv` — исключения и неоднозначности (в этом источнике пусты).
- `literature_discovery.csv`, `source_registry.csv` — библиографическая навигация и результат проверки.
- `request_manifest.json`, `collection_summary.json`, `SHA256SUMS` — происхождение и контрольные суммы.

Из корня ветки:

```bash
python src/collect_pmc_research.py --cache work/external_source_cache/pmc
python -m unittest discover -s tests -p test_pmc_research.py -v
```

Коллектор использует официальные [Europe PMC REST](https://europepmc.org/RestfulWebService) и [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest). Поддержаны cursor-пагинация с проверкой полноты, ограничение частоты до двух запросов/с, повторы временных ошибок, SHA-проверяемый кэш и продолжение загрузки. Версия живого корпуса фиксируется датой, PMCID/DOI и SHA256 ответа. Структуры PubChem сопровождаются ссылкой на [условия использования](https://pubchem.ncbi.nlm.nih.gov/docs/copyright).

Полные исходные XML остаются в `work/external_source_cache/pmc`; для повторной проверки сохранены URL и SHA256. В публикуемый архив входят выбранные данные и подтверждения, без полных статей и лабораторных протоколов. Возможная польза этих 12 строк определяется отдельной абляцией модели; наличие дополнительных строк само по себе не устанавливает улучшение MSE.
