Пакет от 7 ноября 2026 года содержит опубликованные численные данные и ссылки на источники. Это подготовка данных, не новое обучение и не submission. Улучшение MSE внешними строками пока не проверено на исправленных метках.

`si_databases_v2.zip` содержит перечисленные файлы. Загруженный пользователем архив, исходные train_v2/test и значения концентраций организатора в пакет не включены. В таблицах обзора PubChem/ChEMBL сохранены опубликованные численные конечные точки; они отделены от SI и не предназначены для подачи в регрессор как признаки или вспомогательные цели.

## Что изменилось в train_v2

В 320 строках 81 метка изменена с 10000 на 0; остальные метки и порядок SMILES совпадают со старым train. Теперь 83 нуля, ни одного SI=10000, максимум 36066.667. Проверка читает явный список полей: SMILES, strain, Culture, SI VACV; у test дополнительно index. Title, концентрации и признаки их пропусков не читаются.

Используйте новые метки напрямую. Прежний классификатор технического SI=10000 не соответствует этой версии данных. MSE 1228652.39224 для `submission_filtered237.csv` сообщена пользователем, независимо через Kaggle не проверялась; она не является результатом обучения на этом внешнем банке.

## Как использовать без утечки

1. Сначала воспроизвести базовую регрессию на всех 320 исправленных метках, включая 83 нуля. Проверять внешнее дополнение отдельной абляцией на тех же внешних scaffold-фолдах.
2. Для основной абляции взять `augmentation_44_smiles_context_si.csv`. Эти 44 структуры новые относительно train/test, но **не обязательно новые остовы**. В каждом фолде дополнительно исключать внешние структуры/остовы, совпадающие с его проверочной частью; обучать преобразования только на обучающей части.
3. Считать SI единственной целью. Метаданные источника, флаги пересечений, сходство, DOI и индекс не подавать как признаки. Разрешены только SMILES, strain, Culture и их преобразования.
4. Не переводить PubChem `Inactive` в SI=0 или 10000. Не создавать SI из несопоставленных конечных точек и не использовать концентрации как входы/вспомогательные цели. У 390 PubChem и 2160 ChEMBL записей в этом пакете нет проверенной готовой цели SI.
5. Не заменять организаторские метки внешними и не усреднять разные экспериментальные контексты автоматически. Банк SI преимущественно положительный: добавление всех строк может ухудшить нулевые SI и MSE.

Полный банк содержит 32 наблюдения для структур из test и шесть для структур из train. Для консервативной абляции они исключены из файла 44 строк. Полные таблицы нужны для прозрачности происхождения и дедупликации, а не для скрытого переноса ответов в test.

Сходство по Morgan r2/2048 с хиральностью между **test index=233** (строка CSV 235 с заголовком) и обучающим максимумом равно 0.8. Это сходство, не значение SI и не прогноз. Внешние соединения 18b/18a из DOI 10.3390/v15010029 имеют сходство 0.5102/0.4800 с этим test; никаких меток test им не приписано.

Структурные ключи: крупнейший органический фрагмент, нейтрализация и канонический таутомер RDKit; лимиты 100 таутомеров/100 преобразований. Это практическая проверка пересечений, не доказательство исчерпывающей химической эквивалентности. Исходные SMILES сохранены. Версию RDKit фиксирует environment.json.

## Воспроизведение

Из корня репозитория, с локальным архивом пользователя и доступом к закреплённым git-коммитам:

```bash
python -m pip install -r data/si_databases_v2_20261107/requirements.txt
git fetch origin experiment/si-tail-evidence research/external-si-20261107
python src/package_si_databases_v2.py --dataset-zip /path/molecular-activity-prediction-hack.zip --out work/rebuilt_si_database
cd work/rebuilt_si_database
sha256sum -c SHA256SUMS
```

Снимки: `f6dab86fcc4c3b4e5f77eadc89598e23ec468816` (основные внешние данные) и `29c21fa176f4c6d7470c4a2e9914cc40cbd20a51` (14 дополнительных строк). Для тождественного результата нужны Python и версии из environment.json. Скрипт не обучает модель, не обращается к leaderboard и не создаёт submission.
