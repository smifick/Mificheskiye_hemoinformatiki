# VACV: предсказание индекса селективности по SMILES

Обучена модель регрессии **SI VACV**, подготовлен [submission.csv](submission.csv) для **597** тестовых строк. Метрика соревнования — **MSE**. По предоставленному скриншоту первая отправка получила **Public MSE = 9 992 163.26222**, место 2 на момент скриншота. Public-таблица использует примерно 30% test; финальный private-результат неизвестен.

## Результат локальной проверки

Выбрана **Kernel Ridge Regression**, ядро **Tanimoto**, alpha=1, исходная шкала SI. Для выбранной модели используются только Morgan fingerprints; дескрипторы участвовали в сравнении других моделей.

| Проверка | MSE ↓ | RMSE ↓ | MAE ↓ | R² ↑ |
|---|---:|---:|---:|---:|
| Внутренняя scaffold CV, выбранная модель | 20746632.07 | 4554.85 | 3162.53 | 0.090 |
| Отдельный scaffold holdout, выбранная модель | 12350204.88 | 3514.29 | 2774.56 | 0.327 |
| Тот же holdout, среднее по train | 18385782.55 | 4287.86 | 3791.52 | -0.002 |

На этом holdout MSE ниже константного прогноза на **32.8%**. Это локальная оценка на 52 строках, она не гарантирует аналогичного результата Kaggle. Основной результат и сравнение всех 16 конфигураций: [metrics.json](results/final_run/metrics.json), [cv_summary.csv](results/final_run/cv_summary.csv).

## Данные и обнаруженные ограничения

- Train: **320 строк**, **312** уникальных родительских структур после стандартизации; test: **597 строк**, **570** родительских структур. Все SMILES разобраны RDKit.
- **81 из 320** меток равны **10000**. Во всех этих строках отсутствует IC50. По уточнению пользователя, **10000 — служебная кодировка отсутствующего IC50**. Это не значение или граница биологического SI; считать такую метку экспериментально подтверждённым SI нельзя. Для Kaggle они сохранены без подмены.
- Для **237** строк с известными CC50 и IC50 индекс совпадает с CC50/IC50 с относительным допуском 2%. Два CC50 отсутствуют. Есть противоречивые метки одной структуры.
- В train есть **13** многокомпонентных SMILES. Выбрана крупнейшая углеродсодержащая часть, выполнена нейтрализация RDKit Uncharger. Исходный SMILES сохранён; таутомеры не объединялись.
- Повторные строки сохранены как предоставленные экспериментальные наблюдения. В локальном разбиении одна структура и стереоизомеры не попадают в разные scaffold-группы.
- После стандартизации **30** родительских структур встречаются и в train, и в test. Test используется только для финального прогнозирования и аудита структуры; его концентрации не используются в признаках или выборе модели.
- У предоставленных строк нет DOI. В обучающем наборе соответствующие поля оставлены пустыми, ссылки не выдуманы.

## Как обучалась модель

1. Признаки только из SMILES: Morgan, radius=2, 2048 бит, хиральность включена. Для дополнительных моделей — 217 дескрипторов RDKit.
2. Структурные группы: **117 обобщённых каркасов Bemis–Murcko**. Все ациклические молекулы — одна группа. Разделение уменьшает структурную утечку, но не исключает всякое сходство между группами.
3. Внешний holdout: 20% групп с seed=42 → **268 train / 52 holdout**. Группы не пересекаются.
4. На 268 строках — **GroupKFold, 5 фолдов**. Сравнены 16 вариантов: Dummy, Random Forest, Extra Trees, Histogram Gradient Boosting, Ridge и Tanimoto Kernel Ridge; исходная и log1p-шкала SI. Заполнение пропусков и масштабирование обучаются внутри фолда.
5. Выбор по **MSE объединённых внутренних OOF-прогнозов**. Holdout не использовался для подбора. Лучший вариант оценён на holdout один раз.
6. После оценки выбранная модель переобучена на **всех 320 строках** и сохранена. Отрицательные прогнозы обрезаны нулём.

## Внешняя база: фактически выполненная выгрузка

Источник: **ChEMBL REST API**, https://www.ebi.ac.uk/chembl/api/data/ . Найден **621** VACV-анализ, из них **588** функциональных. Выгружено **6510 уникальных endpoint-записей**, все с DOI: **528 IC50, 1709 EC50, 4269 CC50, 4 Selectivity index**. CC50 дополнительно собирались из тех же публикаций и могут относиться к другим экспериментальным контекстам.

- [collected_database.csv](data/external/collected_database.csv) — требуемые поля SMILES, IC50_uM, CC50_uM, SI, doi, а также EC50, оператор отношения и URL. Это длинный формат: одна строка — одно измерение, неизвестные поля пусты.
- [external_endpoints.csv](data/external/external_endpoints.csv) — все данные с assay ID, organism, cell line, описанием и причинами исключения.
- [external_si_database.csv](data/external/external_si_database.csv) — **152 предварительные пары CC50/IC50** с численным отношением, DOI и ссылками на оба измерения. **Все требуют проверки контекста, это не допущенные обучающие метки.**
- [candidate_si_pairs.csv](data/external/candidate_si_pairs.csv) — **337** предварительных пар: 152 с IC50 и 185 с EC50. EC50 не подменяет IC50.
- [direct_si.csv](data/external/direct_si.csv) — два прямых точных SI, оба равны 0, с пометкой о необходимости проверки первоисточника. Другие два опубликованных SI — нижние границы (>52, >750), сохранены в endpoint-таблице с оператором.
- [request_manifest.json](data/external/request_manifest.json) — **44** запроса с URL и SHA256 ответа.
- [collection_summary.json](data/external/collection_summary.json) — итог выгрузки; [vacv_assays.json](data/external/vacv_assays.json) — описания анализов.

**Внешние метки в финальное обучение не добавлены.** У всех найденных пар недостаёт подтверждения условий/времени измерения. Автоматическое отношение концентраций разных экспериментов нельзя выдавать за достоверный SI. Кроме того, такие биологические отношения могут быть несопоставимы со служебной меткой 10000 в организаторском наборе. Расширение обучающей выборки проверенными внешними SI остаётся открытой задачей; улучшение метрики внешними данными не заявляется.

Валидация сохраняет значения >/< как границы и не использует их как точные измерения. Перевод в мкМ разрешён только для распознаваемых молярных единиц; массовые единицы без пересчёта не смешиваются. Получено **2647** записей, прошедших технические проверки endpoint; это не подтверждение сопоставимости анализов.

Условия использования ChEMBL: https://chembl.gitbook.io/chembl-interface-documentation/about/terms-of-use . Атрибуция и DOI сохранены. При повторной выгрузке база может обновиться; проверяйте manifest и версии.

## Запуск с нуля

Проверено на **Python 3.12**, версии библиотек закреплены в [requirements.txt](requirements.txt).

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# Выгрузка внешних данных; требуется интернет, кэш ответов допускает повторный запуск.
python src/download_external.py --out data/external --cache work/chembl_cache

# Обучение, валидация и submission. --out должен быть новым каталогом.
python src/train_model.py --train data/raw/train.csv --test data/raw/test.csv --sample data/raw/sample_submit.csv --out results/reproduced_run

# Независимая проверка сохранённых артефактов.
python src/validate_data.py --run results/final_run --sample data/raw/sample_submit.csv --external data/external --out results/validation_report.json

# Прогноз только по SMILES из сохранённой модели.
python src/predict.py --model results/final_run/model.joblib --input data/raw/test.csv --out results/repeated_submission.csv

python -m unittest discover -s tests -v
python src/make_report.py --root .
```

В Windows: `.venv\Scripts\activate`. Для проверки нового запуска подставьте его каталог в `--run`. Сохранённый joblib загружайте только из доверенного источника.

## Почему первая модель ошибается: разбор после Kaggle

Код отсутствующего IC50 смешан в одной числовой цели с отношением измеренных концентраций. Это отдельная проблема постановки. Отсутствие IC50 не свидетельствует о слабой или сильной активности. Текущий Kernel Ridge обучался воспроизводить предоставленную кодировку Kaggle; прогнозы нельзя считать чистой моделью биологического SI.

Разбор **локальных** отложенных ошибок (не скрытых ошибок Kaggle):

| Метки holdout | Строк | Среднее значение метки | Средний прогноз | Доля суммы квадратов ошибок |
|---|---:|---:|---:|---:|
| Код пропуска IC50 = 10000 | 13 | 10000 | 4918.26 | 55.8% |
| Оба значения концентраций известны | 39 | 127.06 | 2088.39 | 44.2% |

Например, для одной записи с SI=5.111 модель предсказала 6666.17. Модель часто выдаёт промежуточные значения между обычными SI и кодом пропуска. При MSE такое усреднение может быть оптимальным при неопределённости, поэтому простая замена этих прогнозов на 0/10000 сама по себе не гарантирует улучшения.

Пять самых крупных ошибок дают 36.2% суммарной квадратичной ошибки holdout. Во внутренней CV одна запись с известным SI=36066.667 даёт 22.2% суммарной ошибки: большие значения нельзя удалять только из-за их величины. Два организаторских SI=0 совпадают с отсутствующим CC50; трактовка этих нулей также требует уточнения.

Для отдельной научной задачи сохранён [набор из 237 строк с обеими концентрациями](data/processed/si_with_observed_concentrations.csv). Это поднабор для дальнейшей проверки и обучения; текущая модель и submission остались прежними. Пустые концентрации не восстанавливались из служебного кода.

Следующий обоснованный эксперимент — раздельно оценивать вероятность служебной метки и SI при наличии измерений, используя только SMILES. Для MSE прогноз кодированной цели имеет вид `10000 * p + (1 - p) * E[SI | измерение имеется, SMILES]`; это моделирование кодировки, а не биологической неактивности. Возможность предсказывать факт отсутствия измерения по одной структуре ограничена. Для физического SI следует использовать подтверждённые концентрации и проверенные внешние измерения.

Точную причину преимущества лидера узнать по лидерборду нельзя: его метод и скрытые метки недоступны. Для 237 обучающих строк SI вычисляется из имеющихся в таблице CC50 и IC50; правила разрешённых признаков важны для сопоставления решений. Текущая версия сохраняет ограничение SMILES-only.
