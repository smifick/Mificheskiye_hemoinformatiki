# VACV: регрессия индекса селективности по SMILES

Работа на реальных данных начата. Получены train (320 строк), test (597 строк) и шаблон submission. Метрика соревнования — MSE.

Завершено первое сравнение 16 моделей/конфигураций на внутренней scaffold-кросс-валидации. Лучший вариант — Kernel Ridge с Tanimoto-ядром, alpha=1, исходная шкала SI. На отдельной отложенной части: RMSE 3514.29, R² 0.327; RMSE константного прогноза — 4287.86. Выбор сделан по внутренним фолдам, не по holdout.

Обнаружено: у всех 81 строк с отсутствующим IC50 целевая метка SI равна 10000. Это возможная служебная кодировка. Модель обучается воспроизводить предоставленные метки, что не равнозначно предсказанию физически измеренного SI. Признаки строятся только из SMILES.

Выполняется выгрузка внешних измерений ChEMBL: SMILES, IC50/EC50/CC50/SI, DOI и ссылки. Сопоставимость измерений проверяется отдельно; сомнительные отношения автоматически не добавляются в обучение.

Следующее обновление добавит исходный код, обученную модель, проверенный submission.csv, сформированные таблицы и пояснительный документ. Файлы предыдущего технического этапа пока сохранены в корне.
