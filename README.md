# VACV Selectivity Index Regression

Регрессия целевой переменной `SI VACV` по SMILES-представлению молекулы. Решение включает стандартизацию структур, сравнение моделей, структурную валидацию, выгрузку измерений ChEMBL и формирование прогнозов для соревновательного test-набора.

**Версия эксперимента:** `results/final_run`. **Основная метрика:** MSE. **Выбранная модель:** Kernel Ridge Regression с ядром Tanimoto, `alpha = 1`.

## Особенности целевой переменной

Биологический индекс селективности определяется как `SI = CC50 / IC50`. В соревновательном наборе целевая колонка дополнительно содержит техническую кодировку:

- **237 строк:** доступны обе концентрации; SI согласуется с их отношением с относительным допуском 2%.
- **81 строка:** IC50 отсутствует, в `SI VACV` записан код **10000**. Этот код не задаёт величину или границу биологического SI.
- **2 строки:** CC50 отсутствует, в `SI VACV` записано **0**; значение отношения по этим данным не определено.

Текущая модель воспроизводит предоставленную числовую колонку Kaggle. Соревновательная MSE характеризует ошибку по этой кодированной цели. Для отдельного анализа биологического SI подготовлен [поднабор из 237 строк с обеими концентрациями](data/processed/si_with_observed_concentrations.csv); новая модель на нём пока не обучалась.

## Метод и валидация

Train содержит 320 строк и 312 родительских структур после стандартизации; test — 597 строк. Структуры обрабатываются RDKit: выбор крупнейшего углеродсодержащего компонента, нейтрализация, канонический SMILES с сохранением стереохимии. Используются Morgan fingerprints: радиус 2, 2048 бит, хиральность включена. При сравнении дополнительных моделей также рассчитаны 217 дескрипторов RDKit.

Для структурного разделения сформировано 117 обобщённых каркасов Bemis–Murcko. Внешнее разделение: 268 обучающих и 52 отложенные строки; внутренняя проверка — GroupKFold из пяти фолдов. Выбор модели выполнен по MSE внутренних OOF-прогнозов. После оценки выбранная конфигурация обучена на всех 320 строках. Признаки не включают IC50, CC50, названия, культуру или штамм.

## Внешние данные

Выгрузка ChEMBL содержит **6510 endpoint-записей с DOI**: 528 IC50, 1709 EC50, 4269 CC50 и 4 Selectivity index. Из них 2647 прошли технические проверки значения, оператора отношения, единиц и структуры. Сформировано 337 предварительных пар концентраций, включая 152 отношения CC50/IC50.

**Внешние SI не включены в обучение:** метаданные не позволяют подтвердить сопоставимость условий найденных пар. EC50 хранится отдельно от IC50; цензурированные значения не используются как точные метки. Сверены **56 пар IC50–CC50 из двух публикаций** с учётом клеточной линии и авторского определения SI. Добавление проверенных внешних SI было испытано, но не выбрано по MSE. Входы v3 строго ограничены SMILES и обучающей целевой меткой; концентрации и их пропуски не используются как признаки или вспомогательные цели.

## Дополнительные эксперименты

[Экспериментальный submission v2](submission_candidate_v2.csv) представляет ансамбль KRR и модели кодировки пропусков/условного SI. Зафиксированный Public MSE v2: 9681096.22474. Устойчивое локальное преимущество не подтверждено: выбранный кандидат даёт лишь 0.69% снижения OOF MSE, а вложенная процедура выбора — 2.31% роста MSE относительно исходной конфигурации. Основной зафиксированный результат остаётся у первой модели.

Сохранены 21-конфигурационный вложенный эксперимент, 30-конфигурационный интерполяционный benchmark и 23-конфигурационный benchmark центрирования ядра/SVM. [Протокол, отрицательные результаты и файлы](docs/experiment_v2.md).

## Ограничения

Смешение измеренных отношений и кодов пропусков существенно влияет на MSE. На локальной отложенной выборке 13 строк с кодом 10000 дают 55.8% суммы квадратов ошибок. Внутренние CV-результаты использовались для выбора конфигурации и не являются независимой оценкой. Отложенная выборка впоследствии исследована при анализе ошибок; дальнейший подбор по ней потребует новой независимой проверки.

DOI исходных организаторских записей отсутствуют. Условия экспериментов неоднородны, встречаются противоречивые метки одинаковых структур. После стандартизации 30 родительских структур присутствуют и в train, и в test. Прогнозы не устанавливают клиническую эффективность или безопасность соединений.
